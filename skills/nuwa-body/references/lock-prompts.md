# 锁定图提示词

两个模板共用身材卡里"给模型执行的描述"。生成带头版即可，无头版用脚本裁出。

## A：真人 + 紧身打底

```text
模特参考图1，只用来确定长相、发型和肤色。生成同一位成年女性模特的全身身材定妆照，1x3三视图，16:9比例照片，从左到右依次是正面、严格90度侧面、背面，三格是同一个人。

服装：纯黑色无痕紧身打底背心和紧身打底短裤，贴身但不勒肉，看得清身体轮廓。赤脚。
姿势：放松的A字站姿，双臂自然下垂并略微离开身体，双脚与肩同宽。
身材：{整体}。
比例：{比例}。
重点部位：{重点部位}。

构图：三格人物大小一致，头顶到脚底完整入画，脚底在同一水平线，四周留白。浅灰色无缝棚拍背景，有方向的柔和棚拍光，看得清身体曲面的明暗起伏。
真人形象照，真实皮肤纹理，自然的肢体衔接。

头身比例自然，禁止大头娃娃和超小头娃娃，禁止假人质感，禁止过度磨皮、油腻，禁止脏噪点，禁止文字。
```

## B：白模素体

```text
生成一个成年女性人体素体模型的全身三视图，1x3，16:9，从左到右依次是正面、严格90度侧面、背面，三格是同一个素体。

材质：白色哑光的人台素体，表面光滑连贯，没有关节缝、螺丝或拼接线。头部保留完整的头型和大小，没有五官和头发。没有服装。
姿势：放松的A字站姿，双臂自然下垂并略微离开身体，双脚与肩同宽。
身材：{整体}。
比例：{比例}。
重点部位：{重点部位}。

构图：三格素体大小一致，头顶到脚底完整入画，脚底在同一水平线，四周留白。浅灰色背景，有方向的柔和棚拍光，看得清身体曲面的明暗起伏。

禁止关节线、拼接缝、螺丝，禁止服装，禁止文字。
```

## 注意

- 素体没有头发。真人的头发会让头看起来更大，拿素体的头身比和真人对比时要考虑这一点。
- 素体可能被内容审核当成裸体拦下。被拦时如实记录，不要换说法硬绕。
- 两个模板都只在生成锁定图时用。下游穿衣合成用锁定图时，要写明只取身材比例。

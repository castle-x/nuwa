# 身材卡模板

身材卡放在模特档案的 `身材卡.md`。第一层给人看，第二层可以直接拼进提示词。

```markdown
# 身材卡：<模特名>

## 给人看的参数（不进提示词）

- 身高 / 体重：
- 三围：
- 身材定位：<比如：高挑纤细的模特身材>
- 优点：<要突出的>
- 要避开的：<比如：肩膀过宽、小腿粗>

## 给模型执行的描述（可直接拼进提示词）

整体：<一句话，比如：高挑纤细，骨架小，偏骨感>
比例：头身比约 1:8；高腰线，腰部最细处离地约身高的五分之三；腿长超过身高一半；肩窄，腰细，胯略宽于肩；手臂纤细，小腿修长。
重点部位：<形态词，比如：锁骨线条清晰，腰腹平坦有浅浅的马甲线，腿部线条笔直，膝盖骨感，脚踝纤细>

## 锁定图

- A 真人紧身打底：带头 <文件名>，无头 <文件名>
- B 白模素体：带头 <文件名>，无头 <文件名>
- 比例来源图：<一般是 A 的带头版>

## 测量（在比例来源图的正面一格上量）

- 头身比：
- 腰线位置：
- 腿长占身高：

## 确认

- 用户确认：<日期>，<原话>
```

## 从参数翻译到描述

| 给人看 | 给模型 |
|---|---|
| 身高 172、体重 48 | 高挑纤细，骨架小 |
| 腿长 | 腿长超过身高一半，小腿修长 |
| 腰围 58 | 腰细，腰线高，腰部最细处离地约身高的五分之三 |
| 胯宽 | 胯略宽于肩，侧面看臀部线条圆润 |
| 肩窄 | 肩窄，肩线平直，锁骨线条清晰 |

# 定身材

> **付费生成前必须出确认单。** 每次调用生图或生视频接口前，先用同级 `nuwa` 技能里的 `scripts/confirm_sheet.py` 渲染 HTML 确认单，在会话里给出可点击链接，等用户在对话里明确确认再提交。口头列参数不能代替确认单。只有用户本次说了"直接生成""不用问我"才跳过。细则见 [生成前确认](../nuwa/references/confirm-before-generate.md)。

身材这一环要解决两件事：把身材**描述清楚**，再用一张锁定图把它**固定下来**，让后面穿衣服、拍视频时身材不走样。

最容易出问题的是比例：头和身体的大小关系、腰线高低、上下身比例。脸部特写只告诉模型"长什么样"，不告诉它"头有多大"；没有一张图负责比例，模型就会自己拼，结果就是大头娃娃或身材前后不一。

## 交出的东西

| 产出 | 说明 |
|---|---|
| 身材卡 | 两层：给人看的参数，给模型执行的描述 |
| 锁定图 A：真人运动训练服 | 3:2 全身两格＋无头特写，带头版和无头版（正面抠头、侧面打码） |
| 锁定图 B：白模素体 | 全身三视图，带头版和无头版（正面抠头、侧面打码） |
| 测量记录 | 锁定图上量出的头身比、腰线位置、腿长比例 |

带头的锁定图就是这个模特的**比例来源图**，后面合成和生视频时，头身比以它为准。

## 第一步：写身材卡

数字给人看，比例和形态给模型。身高、体重、三围这些数字模型执行不了，要翻译成看得见的比例和形态。模板见 [身材卡](references/body-card.md)。

### 给人看的参数

身高、体重、三围、身材定位、优点、要避开的缺点。用来定方向、和团队对齐，不进提示词。

### 给模型执行的描述

分三块写：

1. **整体**：一句话说清身材类型和气质，比如"高挑纤细，骨架小，偏骨感"。
2. **比例**：这是最重要、也最容易出问题的部分。固定写这几项，都写成相对关系：
   - 头身比，比如约 1:8
   - 腰线位置，比如高腰线，腰部最细处离地约身高的五分之三
   - 上下身比例，比如腿长超过身高一半
   - 肩、腰、胯的宽度关系，比如肩窄，腰细，胯略宽于肩
   - 四肢粗细，比如手臂纤细，小腿修长
3. **重点部位**：按这个模特的定位挑出要强调的部位（胸、腰腹、胯、臀、腿、脚、脖子、锁骨等），每个都写**形态**：
   - 锁骨线条清晰，肩颈线条修长
   - 腰腹平坦，有浅浅的马甲线
   - 腿部线条修长笔直，膝盖骨感
   - 脚踝纤细

   不写直白的词，也不写尺寸。形态描述更容易被模型执行，也更不容易被内容审核拦下。面部表情不放在身材卡里。

## 第二步：生成锁定图

两种素材都出，各自的用处不同：

| 素材 | 能锁住什么 | 要注意的 |
|---|---|---|
| A 真人 + 紧身打底 | 真实皮肤下的身材曲线和比例，最接近成片里的样子 | 打底的颜色和款式可能被带进后面的穿搭，合成时写明"打底不保留，只取身材" |
| B 白模素体 | 最纯粹的身材曲线和比例，没有皮肤、衣服的干扰 | 假人的质感和关节线容易迁移到真人身上；交给下游时写明"只取身材比例，不取质感" |

真人不穿打底会涉嫌裸露，不做这个版本。A 用 [锁定图提示词](references/lock-prompts.md) 开头的标准字段模板：表情、场景、相机参数、画面质感和浅灰色运动训练服逐字复用，只换 `{}` 里的内容（重点部位、身材、肤色、第二格视角）。

两种都按同一个规格出：

- 3:2 横图，一行三格：左边两格各占约 22% 宽，是全身（正面＋背面，或正面＋严格 90° 侧面，按下游需要选，可两版都出）；右边约 56% 宽是不带头的正面半身特写，从锁骨拍到大腿中段，用来看皮肤纹理和腰腹细节（用户 2026-11-17 定，取代原来的 16:9 正面、侧面、背面三视图）
- 全身格保留头部算头身比，但用通用素体头：脸只简化处理，头发盘成紧贴头型的低发髻，露出脖子和后背；人脸四视图不作为参考图
- 放松的 A 字站姿，双臂自然下垂、略微离开身体，双脚与肩同宽，赤脚
- 三格人物一样大，头顶到脚底完整入画，脚底在同一条水平线上
- 浅灰色无缝背景，有方向的柔和棚拍光，看得清身体曲面的明暗起伏

为什么这样排：16:9 的全身三视图只看得出轮廓，看不出皮肤；全身人像宽度只有格高的约 0.35 倍，16:9 时全身格两侧空太多。3:2 让全身更高，右侧特写约 860×1024 像素，足够看纹理。4:3 会让特写格太窄。长发会挡住后背、也让头显大，所以全身格用低发髻。头身比：提示词写 1:7.8 时 GPT Image 实际只画到 1:6.9；写「身高约170厘米……约八头身，头小」「腿长约占身高的55%」后量得 1:8.3、腿长 51%（2026-11-17 Milo桃桃第3版；第4版甲 1:8.6、乙 1:8.2）。模板和迭代记录见 lock-prompts.md 开头。穿衣合成的三视图仍用一行三格全身。

提示词模板见 [锁定图提示词](references/lock-prompts.md)。生成前查 [模型能力速查表](../nuwa/references/model-capabilities.md) 选模型，并把提示词和参考图交给用户确认。

## 第三步：抠出无头版

无头版不单独生成，从带头版处理出来，保证是同一具身体、比例完全一致。去头按格子分开处理，不整行横裁（用户 2026-11-17 定的规范）：

| 格子 | 怎么处理 |
| --- | --- |
| 正面全身 | **局部抠头**：椭圆遮罩从头顶盖到下巴，左右包住耳朵，边缘羽化；遮罩里用同一行头部左右两侧的背景插值补齐 |
| 侧面全身 | **只给脸打码，不抠头**：马赛克盖住额头到下巴、鼻尖到耳前，头发和发髻留着。侧面要靠头的轮廓核对头身比，抠掉就没法量了 |
| 背面全身 | 只露后脑和发髻，不处理 |
| 特写格 | 本来就不带头，不动 |

脖子从下巴以下保留，画布尺寸不变。先在带头版上量出坐标，再处理：

```bash
python3 <skill>/scripts/body_tools.py dehead 锁定图.png --head 291,26,441,230 --mosaic 925,45,1075,240 -o 锁定图-无头.png
```

`--head 左,头顶,右,下巴` 给正面格，`--mosaic 左,上,右,下` 给侧面格，各自可写多次；`--block` 调马赛克方块大小，默认 14 像素。

处理完放大检查：正面格的下巴、嘴唇、发丝不残留，补出来的背景看不出接缝；侧面格认不出五官，头的外轮廓和发髻还在；肩线完整。

旧的 `body_tools.py crop --y` 整行横裁会连特写格和画布一起切掉，只为旧记录保留，不再用。

## 第四步：测量比例

在带头版上量头身比、腰线和腿长，写进身材卡。量法：在正面那一格找出四个点的像素高度，头顶、下巴、腰部最细处、脚底；有需要再加裆部：

```bash
python3 <skill>/scripts/body_tools.py ratio --top 120 --chin 245 --waist 520 --crotch 600 --feet 1100
```

它会算出头身比、腰线在身高的位置、腿长占身高的比例。之后检查合成图和视频截图时用同样的方法量一次，和身材卡对比，头身比偏差超过半个头就要处理。

## 下游怎么用

- **穿衣合成**（`nuwa-wardrobe`）：服装图本身带完整身体时，它负责身材；服装图不带身体时，用锁定图 A 的带头版作为身材比例参考。
- **视频生成**（`nuwa-studio`）：用穿好衣服的成品全身图，它的比例已经继承了锁定图。
- **检查**：任何环节出现身材走样，都回到身材卡和锁定图对比。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 合成图头偏大 | 比例来源是无头图，或脸部特写景别太大 | 用带头的锁定图负责比例，提示词写明脸部图只管长相 |
| 写了身高三围但身材不对 | 模型执行不了测量数字 | 换成比例和形态描述 |
| 锁定图里三格的人大小不一 | 没写"三格人物一样大、脚底在同一水平线" | 补上构图要求重新生成 |
| 真人身上出现假人质感 | 用了白模素体，没写只取比例 | 写明"只取身材比例，不取质感"，或改用锁定图 A |
| 视频里身材被参考视频带偏 | 参考视频里的人体型不同 | 写明"身材以图片为准，不随视频1改变" |

# 参考视频转白模

把参考视频（游戏模型录屏、别人跳舞的视频）先转成一段没有贴图的白模视频，再拿白模当舞蹈复刻的视频1。白模只剩动作、节奏和镜头，原视频里的肤色、发色、戒指、美甲、手套和衣服颜色就不会再迁移到模特身上。

用户说「转白模」「把这段视频转成白模」时，先看原片抽帧，按「出单前要问的选项」问清人物造型、服装、场景和表情，再按「提示词拼装」出单，不用重新摸索写法。

## 什么时候要转

- 原视频里的人外观和模特差得多，复刻时手套、戒指、美甲、发色被照抄。直接用原视频驱动时，伸到镜头前的手会照抄原视频的戒指和美甲；改用白模驱动能解决。
- 原视频是游戏或动画角色，画面带水印、地面阴影或卡通材质。
- 原视频本来就是模特（同一人、同造型）时不用转，直接用。

## 建议：挑参考视频时留意露齿的表情

这是经验建议，不是硬规则。用户挑要转白模的舞蹈时，提醒一次，由用户决定。

建议：原片里有明显露齿大笑、咧嘴的段落，成片大概率也会露齿；想要抿嘴笑或平静表情的，可以优先挑表情收敛的参考视频。

依据：转白模时写死表情上限压不住（见下文表情①的记录）；2026-11-18 Milo 抬臂交叉 720P 驱动时表情段写了「不露齿」，开头那一下仍是露齿大笑。

驱动这一步也可以从锁脸图入手：2026-11-18 起建议锁脸图用表情四宫格，让模型知道这张脸露齿时好看的样子，见 `nuwa-motion`「参考分工」。

## 建议：挑参考视频时看原片人物的身材

这是经验建议，不是硬规则。用户挑要转白模的舞蹈时，提醒一次，由用户决定。

建议：身材会一路传下去：原片人物是什么身材，白模大概就是什么身材，再用白模驱动出成片，成片也会靠近白模的身材，提示词里写的目标身材拉不回多少。想要胸部有分量、抖动明显的成片，优先挑原片人物身材接近目标角色、穿贴身衣服的视频。

依据：2026-11-18 用户对照判断。11-17 两条白长袖短发舞（捂脸、抬臂交叉）原片舞者胸部丰满、穿贴身长袖，白模和驱动成片的胸部体积和抖动都够；11-18 螃蟹舞原片舞者纤瘦、胸小、穿宽松吊带，白模就纤瘦，驱动成片（2fcc8a2a）其他都满分，唯独胸部抖动没达到预期。对照图：项目 `图片/临时图/黑吊带牛仔裤长直发螃蟹舞参考视频/原片与白模身材对照-捂脸-抬臂-螃蟹.png`。

反例和没分开的变量：螃蟹舞白模同时还换了写法（不穿衣服、去掉胸部体积句、「胸部」改成「上半身和腰腹」、表情改平静、人物在画面里更小），这些也可能削弱抖动，没有单独对照过。原片身材对不上时，在白模这一步传角色的无头身材锁定图把身材换掉，2026-11-18 已验证有效，见「白模身材锁定成角色的」。

## 参数

- 模型 `wan3.0-video`（2026-11-16 同提示词对照：MiniMax-H3-Lite 只改了头和衣服，手、美甲、背景都不动；MiniMax-H3 背景只去色、动作晚半拍、强制带音轨，且更贵。转白模用 Wan 3.0），参考生视频模式：传视频1（reference_video）；人物造型选④时，再传一张目标角色的单张 1:1 正面头像当图片1（reference_image），**必须是灰度版**，彩色的人脸或服装锁定图会把颜色带回白模。其余选项只传视频1，不传参考图。
- `audio=false`，`prompt_extend=false`，`watermark=false`。
- 时长等于要用的那段参考视频，比例按成片定。参考视频（reference_video）最长 15 秒，超过直接报 `InvalidParameter`（2026-11-18 实测 20 秒被拒）；更长的舞要切成 ≤15 秒的几段分别转。
- 分辨率默认 480P：白模只当动作参考，480P 够用，计费也低。要截白模单帧画骨架时才用 720P。
- 计费按输入加输出两段时长算，先把原视频截到需要的长度、去掉音轨再传。
- 舞蹈是循环动作时，先测出一个循环的长度（逐帧比对找最相似的帧），只截一个循环多一点。

## 规则

1. **只改外观，其余一比一。** 动作、动作时机和表情都写「与视频1一致」，不要逐段复述动作。逐段复述动作、顺手改表情，会少拍、动作时机提前、表情走样；只写一比一复刻、只换外观，时机和表情才对得上。
2. **出单前先问清选项。** 人物造型、服装、场景、表情各有几种做法，原片身体晃动明显时还有身体肉感浮动，按用户的选择拼提示词，不要套一个固定版本。默认值只是推荐，用户没选之前不要替他定。场景尤其要问：原片背景乱、带舞台特效、字幕、水印、画中画或多镜头剪辑时，推荐直接去掉场景，换成浅灰色无缝影棚。

## 默认模板：驱动已定角色（用户 2026-11-18 定）

已经知道要驱动哪个角色时，白模默认用这一套，不再逐项问服装、表情和构图。依据：用户认为 11-17 两条 Milo 脸型版白模（捂脸 `186510fb`、抬臂交叉 `634b786d`）是最满意的白模；11-18 螃蟹舞换成不穿衣服、表情平静、改写构图后，成片胸部抖动明显变弱。

- **服装固定贴身连体衣**（服装②）。不穿衣服（服装③）不再用：抖动会变弱，而且「没有任何衣服」加胸部描述会被 Wan 文本审核拒。
- **优先级、动作、表情、构图与运镜**照抄 11-17 那两条，见下面的提示词。
- **身材锁定成角色的**：同时传角色的无头身材锁定图（灰度），写法见下一小节。下面的提示词是不传身材图的原版。
- 场景默认浅灰无缝影棚，原片背景本来就要用时再问。
- 仍要问的只剩场景和身体肉感浮动；用户这次已经说了的不再问。

```text
优先级：动作、动作时机、表情出现的时机和身体的肉感抖动与视频1一致，只把整个画面换成白模；白模的头型和脸型照图片1，不照视频1里的这个人。
人物：视频1中的这个人，变成通体浅灰白色哑光的光头白模，没有头发，不戴首饰。头型和脸型照图片1：<一句话写这个角色的头型和脸型>；五官的位置和比例照图片1。图片1是灰度的人脸参考图，只提供头型、脸型和五官比例，不取头发和皮肤质感。身体是有肉感的柔软真人身体，不是硬塑料人偶，胸部体积和身体曲线与视频1一致。手和指甲也是同一种浅灰白色哑光材质，没有美甲和戒指。
表情：表情出现的时机跟随视频1，幅度收敛：嘴唇闭合或只微微张开，笑的时候嘴角上扬、眼睛可以弯成眯眯眼；不张大嘴，嘴不张成圆形，不嘟嘴，不露舌头；脸颊保持平滑，苹果肌不鼓起。
动作：每个动作的顺序、幅度和时间点与视频1逐帧对齐，不提前、不省略任何一拍。胸部和腰腹随每一次落拍、扭胯和甩手大幅度地晃动、回弹，晃动幅度比视频1更大、更夸张，时间点仍与视频1一致，停顿时还有几下明显的余震。
服装：只穿一件贴身无缝的白模紧身长袖连体衣，和皮肤同一种材质，只看得出身体轮廓。
场景：浅灰色无缝影棚，地面和背景墙平滑过渡，没有家具、门框和灯光特效。画面里只有这一个人。
构图与运镜：与视频1完全一致。
画面质感：三维白模渲染质感，画面清晰，动作流畅，不要文字、字幕、水印。
```

### 白模身材锁定成角色的（用户 2026-11-18 定，已验证）

**驱动已定角色时，白模一律同时传角色的无头身材锁定图，把白模身材换成角色的。** 身材会从原片一路传到白模、再传到成片（见上文「挑参考视频时看原片人物的身材」），在白模这一步换掉，下游才拉得回来；到驱动那一步再用提示词强调身材，效果有限。

- 图片2：角色的无头身材锁定图，**先转灰度**另存（彩色会把肤色带回白模）。Milo：`图片/参考图/身材/Milo桃桃/Milo桃桃-身材锁定图A-第4版甲-正面背面-无头-2K-HAT-灰度.png`。
- 优先级末尾：「白模的头型和脸型照图片1，身材照图片2，都不照视频1里的这个人。」
- 人物段把「胸部体积和身体曲线与视频1一致」换成：「身材照图片2：胸部体积、腰胯比例、臀部和腿长都照图片2，不照视频1里的这个人；图片2是灰度的无头身材参考图，只提供身材比例和形态，不取衣服、肤色和头发。」其余字段照上面的模板。

验证：2026-11-18 螃蟹舞，原片舞者纤瘦、胸小。只用 11-17 模板时（且当时不穿衣服），白模跟着纤瘦，驱动成片胸部抖动不够；加身材锁定图后（4 秒试跑 `e398768b`，确认单 `任务-黑吊带牛仔裤长直发螃蟹舞-白模视频-Milo脸型身材锁定版-4秒试跑-480P-Wan3.json`），白模换成了 Milo 的沙漏身材：胸部更饱满、腰更细、胯臀更宽，动作时机和机位与原片仍然一致。用户评价「非常非常非常成功」。穿比基尼的身材锁定图过了 Wan 的输入审核。

证据边界：只验证了一次 4 秒、一个角色；身材和原片舞者差得更远（例如原片是男性或体型差很多）时，动作会不会变形还没试过。

## 出单前要问的选项

用 AskUserQuestion 一次问完（最多四问），每问把推荐项放第一个，并在说明里写依据（看过原片抽帧再推荐）。

| 选项 | 做法 | 什么时候推荐 |
|---|---|---|
| **人物造型** | ① 保留造型轮廓：发型、帽子、配饰都留，只去掉颜色 | 视频1 就是要复刻的角色（游戏原角色、同款 cosplay） |
| | ② 光头去饰品：光头，不戴帽子、首饰、手套 | 视频1 是别人、还没定要驱动哪个模特 |
| | ③ 光头人偶：通用白模脸，无个人长相，只保留表情 | 原片人的长相、妆容特别强，怕被带进第 2 步 |
| | ④ 光头＋目标角色脸型：同时传目标角色的单张 1:1 灰度正面头像，头型、脸型和五官比例照它 | 已经知道要驱动哪个模特（默认）。白模更真实，脸更接近要的人，第 2 步驱动时脸也更容易对上 |
| **服装** | ① 保留款式，变成白模材质 | 模特之后要穿相近的衣服，或衣料摆动要当参考（默认） |
| | ② 换成贴身连体衣，只看得出身体轮廓 | 原片衣服和模特衣服差得多；驱动已定角色时固定用它（用户 2026-11-18 定） |
| | ③ 不穿衣服，人体模型 | 只要动作骨架；抖动会变弱，且容易被文本审核拒，驱动角色时不用 |
| **场景** | ① 保留结构，变成白模 | 场景简单、要在第 2 步还原同样的空间（门框、墙角） |
| | ② 去掉场景，换成浅灰色无缝影棚 | 背景乱、舞台特效、字幕水印、画中画、多镜头 |
| | ③ 保留原场景原色，只把人换成白模 | 场景本身就要用，只想去掉人的外观 |
| **表情** | ① 跟随视频1但收敛（默认） | 白模的脸容易把表情演得夸张、发假，默认用这档 |
| | ② 与视频1严格一比一 | 表情幅度本身就是内容（吐舌、大笑这类要原样保住） |
| | ③ 改成平静、嘴唇闭合 | 原片表情夸张，角色设定不笑（注意：改表情会让动作时机变差） |
| **身体肉感浮动** | ① 不单独写（默认） | 原片没有明显的身体晃动，或只要骨架动作 |
| | ② 跟随原片 | 原片的肉感抖动是内容的一部分，按原片幅度保住 |
| | ③ 比原片更夸张 | 用户要强调肉感，之后驱动模特时想让晃动更明显 |

原片能看到明显的身体晃动（贴身衣服、胸部和腰腹随动作起伏）时，要问「身体肉感浮动」。一次最多问四个，用户已经指定的选项（例如「背景全去掉」）不再问，把空出来的位置留给这一问。

机位默认「与视频1完全一致」，用户要改机位时按下面「转白模时顺便改机位」一节处理，不放进这几问。

### 白模的脸：传目标角色的头部参考图

2026-11-17 用户在另一个会话测通：转白模时同时传目标角色的头部参考图，白模更真实，脸也更接近想要的人。实测批次 `2026-11-17 白长袖短发捂脸手势舞-白模视频-Milo脸型版-11秒-480P-Wan3`，图片1用的是 `Milo桃桃-人脸四视图-拼合-2K-HAT-灰度.png`（人脸四视图拼合，HAT 放大到 2K，再转灰度）。用户 2026-11-17 定：以后图片1固定用**单张 1:1 头像**，即目标角色的正面头部图，裁成 1:1，转成灰度，不再用四视图拼合图。

写法（人物造型④）：
- 优先级末尾加：「白模的头型和脸型照图片1，不照视频1里的这个人。」
- 人物段：「视频1中的这个人，变成通体浅灰白色哑光的光头白模，没有头发，不戴首饰。头型和脸型照图片1：<用一句话写这个角色的头型和脸型特征>；五官的位置和比例照图片1。图片1是灰度的人脸参考图，只提供头型、脸型和五官比例，不取头发和皮肤质感。」
- 图片1：从人脸锁定图里取正面那一格，裁成 1:1 的头像（头顶到下巴完整、两侧留一点空），转灰度后另存，原图不动。

试过但不再用的：先用 `脚本/视频遮脸.py` 把原片的脸模糊掉再转白模，能收住夸张表情（11-17「白长袖短发室内手势舞」遮脸输入版），但用户 2026-11-17 定不再用这种方式，改用上面的头部参考图。

## 提示词拼装

固定骨架，花括号里按选项替换成对应的句子；每个字段只写所选那一句。

```text
优先级：动作、动作时机和表情与视频1一比一完全一致，只把{人物/人物和衣服/整个画面}换成白模。
人物：{人物造型句}手和指甲也是同一种浅灰白色哑光材质，没有美甲和戒指。
表情：{表情句}
动作：每个动作的顺序、幅度和时间点与视频1逐帧对齐，不提前、不省略任何一拍。{有头发、长衣料时加惯性句}
服装：{服装句}
场景：{场景句}画面里只有这一个人。
构图与运镜：与视频1完全一致。
画面质感：三维白模渲染质感，画面清晰，动作流畅，不要文字、字幕、水印。
```

表情选①（收敛）或③（平静）时，优先级里的「表情」改成「表情出现的时机」，否则「表情与视频1一比一」会压过表情段的上限（2026-11-17 第一次收敛没压住，优先级还写着表情一比一）。

优先级里的范围按选项定：场景选①或②时写「整个画面」，选③时写「人物」。只写「人物」时，模型容易只改人、不动背景。

各选项对应的句子：

- 人物造型
  - ① 「就是视频1中的这个角色，脸、发型、帽子、服装和配饰的造型全部保留，只是变成通体浅灰白色哑光的白模。<发型一句>；头发是真实的发丝质感，有蓬松度和层次，不是一整块硬片。」
  - ② 「视频1中的这个人，变成通体浅灰白色哑光的光头白模，没有头发，不戴帽子、首饰和手套。」
  - ③ 「视频1中的这个人，变成通体浅灰白色哑光的光头人体模型，像美术用的人偶，表面光滑。脸是没有个人特征的通用白模脸，只保留眉、眼、嘴的基本形状，用来呈现表情。」
  - ④ 见上面「白模的脸：传目标角色的头部参考图」。
- 服装
  - ① 「衣服保留视频1的款式：<逐件列出>，同样是浅灰白色哑光材质。」
  - ② 「只穿一件贴身无缝的白模紧身长袖连体衣，和皮肤同一种材质，只看得出身体轮廓。」
  - ③ 「全身是一体成型的浅灰白色哑光人台材质，像美术用的人体模型，没有衣物的结构和褶皱。」2026-11-18 原写法「没有任何衣服」和胸部抖动句同时出现，被 Wan 3.0 文本审核拒（`DataInspectionFailed: Green net check rejected text`）；选③时肉感句也不写「胸部」，改「上半身和腰腹的柔软部位」「身体曲线和体积与视频1一致」，这样能过审。
- 场景
  - ① 「视频1的<场景名>，同样变成浅灰白色哑光白模，<关键结构>位置不变。」
  - ② 「浅灰色无缝影棚，地面和背景墙平滑过渡，没有家具和灯光特效。」

  - 人物段的肉感身体句：「身体是有肉感的柔软真人身体，不是硬塑料人偶，胸部体积和身体曲线与视频1一致。」白模容易把胸部和腰臀收成标准人台，体积变小，抖动也会跟着变弱，所以体积要一起写。
  - ② 动作段：「胸部和腰腹随每一次落拍、扭胯和甩手自然晃动、回弹，抖动的幅度、节奏和时间点与视频1一致，停顿时还有细小的余震。」

- 表情
  - ① 「表情的种类和出现时机跟随视频1，幅度比视频1收敛一些，不额外添加视频1里没有的表情。微笑时只是嘴角轻轻上扬，脸颊保持平滑放松，不挤出法令纹，苹果肌不鼓起。」用户 2026-11-17 反馈：一比一的白模表情特别夸张和假，微笑时常出现奇怪的法令纹和鼓起的苹果肌；要学原人的表情，但不自己加戏，收敛一点。同日用这句跑「白长袖短发室内手势舞」8 秒：中后段平静了，但开头原片只是微张嘴露一点上牙的微笑，白模仍张成咧嘴大笑，露出舌头和下排牙，眼睛还斜眯。「收敛一些」这种相对说法压不住，改成写死上限（「嘴最多微微张开，只露出一点上排牙齿，不露舌头和下排牙；眼睛自然睁开不眯」，优先级只写表情时机）再跑，开头仍是咧嘴露上下牙、眼睛斜眯，和收敛版几乎一样：参考生视频模式下，视频1里的脸部表情压过表情段的文字，靠提示词压不住。表情幅度要配合人物造型④一起处理（遮脸输入能收住，但用户已定不再用）。

### 常用组合

- **模板 A（保留造型，只去贴图）**：人物①＋服装①＋场景①或②＋表情①或②。适合游戏模型查看器录屏这类素材，动作、服装轮廓和头发衣料的摆动都能保住。
- **模板 B（换人，只留动作）**：人物②＋服装①＋场景①＋表情①。带推拉镜头的真人舞台视频也能用；前景的摄像机、观众后脑勺可能不会被刷白，不影响当动作参考。
- **干净动作参考**：人物④（未定模特时用②或③）＋服装②＋场景②＋表情①。原片背景复杂或之后要换到别的场景时用。

## 转白模时顺便改机位

白模这一步不只去外观，还能锁表情、改机位，再驱动角色时脸也更像本人。改机位都放在白模这一步做：

1. **只在提示词里改机位，不生效。** 只传视频1、写「摄像机抬高、斜向下45度」，出来仍是原片机位：参考视频的镜头压过文字。
2. **先出一张目标机位的白模图，再和视频一起传，才生效。** 用 Nano Banana Pro 把原片一帧改成目标机位的白模（取图自检不允许拿本项目生成的白模帧当输入，用原片截帧，一步完成转白模和改机位）。提示词写明「机位按图片1，不按视频1」。代价是一张参考图只能撑住前几秒，之后机位会慢慢回落到原片，**固定机位变成运镜**。
3. **角度数字不可靠。** 白模图写 45 度偏高；写 25 度出成了平视、看得到天花板；写 35 度又和 45 度差不多。用画面里能看到的东西卡位置更稳：看不看得到天花板、双脚和地面占画面多少、门框上沿在哪。

**用户强调固定机位时，还没有可靠做法。** 先告诉用户这个风险，再试这几条（都未验证）：

- 优先级和构图段都写「全程机位不变、俯视角度从头到尾一致、双脚始终在画面里」。
- 把参考视频切成 4 秒左右的几段分别出白模，每段都传同一张目标机位图，再拼起来。
- 改用首尾帧模式，首帧和尾帧都用目标机位的白模图（Wan 3.0 首尾帧模式不能再传参考视频，动作跟随会变弱）。

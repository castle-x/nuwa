# 视频总览页（白模 / 成片对比原片）

一批白模或舞蹈成片出来后，用这个页面把所有结果并排放着看、和原片对照。版式来自 2026-11-17 用户认可的 `参考资料/视频/白模总览.html`（「整体设计都挺好，希望把 HTML 的规范保留下来」）。

## 怎么生成

不要手写 HTML，用脚本：

```bash
python3 scripts/video_overview.py --示例          # 打印任务 JSON 模板
python3 scripts/video_overview.py 白模总览.json   # 按 JSON 生成，输出到 out
```

- 项目里的任务 JSON 和页面放在一起：`参考资料/视频/白模总览.json` → `参考资料/视频/白模总览.html`。新出一条就往 JSON 里加一张卡片再跑脚本，不直接改 HTML。
- 路径一律写绝对路径；页面里的视频地址由脚本换成相对 HTML 的地址，所以页面要和视频在同一个工作区里打开。
- 脚本会报出缺失的文件，有缺失先补齐再给用户。
- 生成后用系统浏览器打开（`open 白模总览.html`），把绝对路径发给用户。

## 页面规范

改版式前先改这里，再改脚本。

**结构**
- 单行顶栏（毛玻璃、吸顶）：页面标题、播放控制分段胶囊「全部播放 · 全部暂停 · 从头同步」、右侧一句操作提示。不另起工具栏。
- 按「线」分组：每组一个小标题「组名 · N 条」，第一组标题前加一颗强调色圆点标出当前主线；其余角色归「其他角色」。
- 组内是自适应网格（卡片最小 230px），新的在前。

**卡片**
- 上部是 9:16 舞台，视频 `object-fit: contain` 不裁切，左上角半透明日期胶囊（`11/17`）。
- 下部依次：标题「动作名 · 版本差异」，单行省略；元信息「时长 · 模型 · 分辨率」，当前最新的一条末尾加「最新」；分段胶囊；文件名。
- 分段胶囊是这张卡的核心：同一个舞台里切换「白模」「对照原片」「片段（如 前4秒、2秒起-6秒）」，第一个永远是成片本身。对照原片用「左原片右白模」的并排视频（见 [参考视频转白模](white-model-video.md) 的出片后检查）。没有对照或片段时只留一个分段。
- 文件名是可点的按钮，点了复制成片的绝对路径，底部弹「已复制路径」小提示。

**播放**
- 页面打开即全部静音循环播放，方便一眼扫完动作时机。
- 「从头同步」把所有视频拉回 0 秒一起播，用来横向比较同一段动作。
- 悬停一张卡片时只播它、其余暂停；移开恢复全局状态。

**视觉**
- 暖灰底、白卡、14px 圆角、细线描边，强调色暖橙只用在圆点、文件名悬停和焦点环上。
- 明暗两套 token 都在 `:root` 里，跟随系统。
- 控件只有胶囊分段一种形态，选中项是浮起的白底胶囊。

# 细节打磨

> **付费生成前必须出确认单。** 每次调用生图或生视频接口前，先用同级 `nuwa` 技能里的 `scripts/confirm_sheet.py` 渲染 HTML 确认单，在会话里给出可点击链接，等用户在对话里明确确认再提交。口头列参数不能代替确认单。只有用户本次说了"直接生成""不用问我"才跳过。细则见 [生成前确认](../nuwa/references/confirm-before-generate.md)。

生成出来的东西，第一眼"差不多"不代表能发。这一环的工作是：看清楚哪里不对，找到原因，用最小的改动修好，并把修法记下来，下次不再犯。

## 先看，再改

不要只看首帧或凭感觉判断。用脚本抽帧：

```bash
python3 <skill>/scripts/inspect_video.py 视频.mp4 -o 检查帧/
```

它会输出：

- `sheet.png`：全片总览，每 0.5 秒一帧，看整体动作、构图和画面边缘。
- `info.txt`：分辨率、帧率、时长、帧数。

发现某一段有问题时，裁出局部的连续帧细看：

```bash
python3 <skill>/scripts/inspect_video.py 视频.mp4 -o 检查帧/ --crop 250,140,200,200 --start 2.5 --end 4.5
```

`--crop x,y,宽,高` 按原视频像素裁出一块（通常是脸，或画面左右边缘），在 `--start` 到 `--end` 秒之间连续取帧，拼成 `crop.png`。脸部漂移、手指异常、边缘入画都要这样看，总览图上看不出来。

把检查结论写进这次生成记录的 `检查记录.md`：通过项、问题项（带时间点）、复核用的帧图。

## 诊断，然后只改一个变量

对照 [问题图谱](references/failure-atlas.md) 找原因。每个问题都有"最可能的原因"和"先试的修法"。

一次只改一处再重新生成。同时改分辨率、动作和参考图，结果变好了也不知道是哪一处起的作用，下次遇到同样的问题还得全部重来。

修法要先问自己：这是提示词能解决的，还是模型或分辨率的上限？比如全身构图下 720×960 的视频，脸只有约 70 像素高，再怎么写"面部清晰稳定"也有限，该做的是拉近构图、提高分辨率或换模型。

## 修不好时的后期手段

| 手段 | 用途 | 注意 |
|---|---|---|
| 换一次种子重生成 | 偶发问题 | 同一问题连续两次出现，就不是运气问题，回去改原因 |
| 视频换脸 | 脸部轻微漂移，其他都好 | 用角色锁定的身份图做源。逐帧的人脸修复（如 CodeFormer）会让脸更闪，不要用 |
| 静态图超分 | 成品图要放大到 4K/8K | 用 `image-upscale`，只放大不重绘，脸不会变 |
| 裁切 | 画面边缘有入画的手或器材 | 会改变画幅和构图，确认用户能接受 |
| 快切剪辑 | 多套衣服、多段素材拼成一条 | 见下 |

## 图片皮肤像手办：分格修复

定妆多格图（四视图、三视图）磨皮太重、皮肤像手办时，不要把整张图送去修：模型会按输出比例重排版面，没头的格子会被补出头，特写格会被拆开，格子太小皮肤也修不透。做法：

1. 按分隔线把要修的格裁出来，只裁露皮肤的格，裁成接口支持的比例（全身格取上半身 9:16，头部特写 3:4）。
2. 每格单独用 Nano Banana Pro 修，提示词只改「皮肤」「纹身」两段，其余写「保持参考图1不变、不扩展不缩放画面」。皮肤写具体的真实细节（毛孔大小不均、半透明感和皮下血色、脊柱沟和肩胛骨起伏、腰侧细褶皱、汗毛绒光）；纹身写成「刺进皮肤里的墨色，随肌肤起伏，边缘轻微晕开、略褪色」；锁住瞳色和妆线，并写明不加雀斑和痣，否则会自己加上。
3. 把每格缩放回原区域贴回原图，下边裁切处做 80px 渐变过渡，没修的格保持原样。

做对比页时用拖动分界线的前后对比，方便看脸有没有崩、哪些细节被改。

## 剪辑

先确认是否真的需要剪辑。Wan 3.0 单条成片不剪辑直接发，真实感最强。

需要剪辑时：

- 多套衣服默认按套装分组：第一套内部快切完，再切到第二套，整条只换一次套装。不要两套交替切。
- 保持原速，靠选段和直接切换形成节奏，不调速。调速要有理由并记录。
- 单个片段常见 0.6～1 秒，按参考节奏和动作决定。
- 按帧算时长：15 秒、30fps 就是 450 帧。成片导出后再核对一次实际帧数和时长。
- 同一段素材里首尾相连的两个片段，拼接后看起来是连续的，不算一次切换。核对实际的可见切点。

## 验收

交付前逐项过：

1. 规格：实际像素、帧率、时长、帧数、音轨，完整解码无报错。
2. 身份：首尾帧和动作变化最大的那几帧，脸是不是同一个人。
3. 比例：头身比和身材卡是否一致。
4. 服装：数量、颜色、五金、不对称的细节有没有在中途变化。
5. 画面边缘：有没有入画的手、相机、器材之外的东西。
6. 手：手指数量、和衣料的接触有没有穿模，有没有悬停不动的手。
7. 用户明确要求去掉的东西（包、手套）有没有残留。

没检查到的部分如实说明，比如"只看了每 0.5 秒一帧，没有逐帧排查手指"。不要因为抽查通过就说全片没有问题。

# 棚拍花絮

花絮的真实感来自三样东西：画面边缘露出的器材、手机手持的轻微晃动、模特不看手机镜头。节奏感来自闪光灯：每闪一次换一个姿势。

公共规则见 `nuwa-motion`，场景配方见 `nuwa-set`。这里只写花絮特有的部分。

## 流程

1. **要一张对标图。** 真实的棚拍花絮截图最好，从里面读出机位、景别、器材位置和画幅，整理成场景卡。
2. **定机位关系。** 手机在主摄旁边，几乎正面；模特面向主摄，所以视线朝向画面一侧，不看手机镜头。
3. **设计姿势。** 8 秒 3 个姿势，每个定格约 2 秒。至少一两个姿势要换重心或换脚，否则看起来像没换。
4. **写提示词，提交，检查。** 重点检查画面左右边缘有没有摄影师的手臂、相机入画。

## 花絮特有的写法

- **用闪光当节拍器。** 写"画面外的闪光灯每闪一次，模特换一个姿势"，不写"摄影师每按一次快门"。少提摄影师，模型就少画摄影师。
- **把画面边缘写具体。** 只写"主摄影师不出镜"往往不起作用，模型会在边缘补出相机和手。用具体的器材占住边缘位置，再写一句"画面里只有模特一个人，没有相机、手、手臂或任何其他人体部位"。
- **身体动，头少动。** 换姿势靠身体、手臂和腿，头部几乎不动，脸始终朝向镜头一侧；长发写明一直垂在肩后，不遮挡面部。
- **声音帮节奏。** 快门的咔嚓声、闪光灯回电的嘀声，和姿势切换对齐。

## 示例提示词（Wan 3.0）

参数：`wan3.0-video`，720P，3:4，8 秒，`audio=true`，`prompt_extend=false`。

```text
竖屏 3:4，手机手持拍摄的摄影棚工作花絮，8 秒，一镜到底。

@图片1 是人物面部的三视图，全片严格保持这张脸的五官、脸型、眼型和妆容，面部清晰稳定。@图片2 只提供服装和身材，图中没有头部只是因为裁掉了，人物的头部和脸完全以图片1为准。

场景：浅灰色无缝背景纸，墙面与地面弧形过渡。画面左侧边缘露出银色反光伞和灯架，右下角露出灯架轮子。画面里只有模特一个人，没有相机、手或其他人。
机位：手机在主摄旁边，几乎正面，腰部高度略微仰拍，人物居中全身，头顶留出空间，轻微手持晃动。

动作：画面外的闪光灯每闪一次，模特换一个姿势，换好后定格约 2 秒。换姿势主要靠身体、手臂和腿，头部几乎不动，脸始终朝向镜头左前方，表情松弛冷淡，长发一直垂在肩后，不遮挡面部。
1. 一手插兜，重心落在右腿上
2. 双手拉住裤腰，重心换到左腿，肩膀微微放松
3. 一手垂在身侧，另一只手轻搭在腰侧，最后轻轻抬眼看向左前方

声音：快门的咔嚓声、闪光灯回电的嘀声、棚内环境音。
```

复用时注意：

- 参考图优先换成角色包里的成品全身图，比"面部锁定图 + 无头身体图"更不容易偏大头。换了之后，把第二段改成"图片1是这位模特的全身照，提供身份、服装和身材比例"。
- 画面边缘仍可能出现手臂，生成后检查左右边缘。
- 姿势要写出换重心或换脚，否则变化不明显。

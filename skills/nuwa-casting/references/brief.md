# 需求边界

需求边界写的是用户的目标，不是你的方案：这个角色拿去干什么、给谁看、在什么镜头和画幅里出现、第一眼要让人产生什么印象、哪些东西绝对不能出现。方案写在 [设计方案](treatment.md) 里，两者不混。

## 一次只问一个决定

用户带着模糊直觉来时，最有效的是把他还没决定的那件事摆成两三个能直接比较的选项。真正影响方向的只有四类：

| 决策 | 为什么必须问 | 怎么问 |
|---|---|---|
| 呈现场景与载体 | 短视频出镜、直播、平面视觉、剧情角色，对镜头距离、光线、服装的要求完全不同 | "这个角色主要在什么镜头里出现？镜头离人多近？" |
| 第一眼气质与年龄感 | 清冷疏离和松弛亲和是两套骨相，不是两段形容词 | 给两三组反差鲜明的气质加骨相组合，让他凭直觉选 |
| 辨识度与审美红线 | 决定哪三到五个结构必须保住，要排除哪些生成痕迹 | "最想让人记住这张脸的哪一点？最反感哪种网红感？" |
| 使用方式 | 单张出图、成套定妆、要接视频、以后还要不要换装 | 决定要不要一开始就做锁定图和锁定设定 |

一次只推进当前最关键的一两个。其余等方案成形后再问，用户在看到具体方案之前，往往不知道自己在意什么。

有参考图时，在写提示词前再问三件事：原发型、妆容要不要保留（服装、配饰分别问）；带表情还是无明显表情（默认无明显表情）；皮肤高光保留参考图的光泽，还是适度减弱油光。

## 用户说不清的时候

直接要参考图，比自己猜更准。顺手说清"想要的是这张的轮廓，还是这张的神态"。

连参考都没有时用反差法：给两组互斥的方向，比如"偏长的鹅蛋脸、山根低、唇部饱满，冷感来自中庭偏长"对"方圆脸、下颌角清楚、鼻梁直挺，气场来自量感"，让他选更接近的一个，再追问"哪个部分不像"。

## 写下来的样子

放在档案的 `需求边界.md`：

```text
用途：             什么平台、什么镜头、多久出现一次
画幅与场景：       竖屏特写 / 半身 / 全身；室内自然光 / 棚拍
第一眼气质：       两三个词，加一句为什么
年龄感：           具体年龄段，不写"年轻"
必须保住的记忆点： 具体到结构，不写"有辨识度"
审美红线：         明确排除的生成痕迹
后续用途：         是否接视频、是否换装、是否需要衣橱
发型选择：         保留参考图原发型 / 调整为……
妆造选择：         妆容、服装、配饰分别写保留或调整
表情选择：         默认无明显表情 / 用户指定的表情
皮肤高光：         保留参考光泽 / 适度减弱油光 / 用户指定程度
核验限制：         保留造型时，遮挡或妆容会影响哪些判断
已拍板 / 待定：    哪些是用户定的，哪些是你这次的提案
```

"已拍板"和"待定"要一直分清。用户拍板过的骨相，下一轮不能因为你觉得更好看就改掉；你的提案被否掉时，改的是提案，不是需求边界。

## 什么时候改

用户的目标变了才改：用途从平面变成直播、从单人变成系列角色、审美红线的说法变了。"这一版不好看"不算，那是方案或提示词的问题。

# 面部锁定图提示词

## 写法原则

- **人脸长相交给参考图。** 参考图给够了，五官就不用文字描述。脸很难用文字描述准确，写多了反而会和参考图抢话语权。
- **其他维度用文字写死。** 拍摄语境、格位视角、构图、背景、光线、色调、造型、服装、表情，参考图给不了这些，不写模型就自己定，比如不写背景可能出纯黑背景。
- **真人感要求要写。** 自然的不对称、不抹平中面部、干净的照片肤质、反向锁定，这些和长相无关，有参考图时也要写。依据见 [画质与真人感](realism.md)。
- **按模型调整肤质写法。** 下面的模板按 GPT Image 写：要干净，不要细节词。换成 Nano Banana 系列时，肤质一行可以换成具体的细节词，见画质与真人感里的"按模型调整"。

提示词默认用中文写。模型或使用者需要英文时再翻译。

## 基准脸（先出这一张）

单张大图，既用来确认长相，也用来判断肤质。

```text
生成一张真人照片：用定焦人像镜头拍摄的正面头肩照，未经后期精修的相机原片。附带的参考图都是同一位成年女性，她的长相完全以参考图为准；只取参考图前景里的这个人，忽略屏幕、其他人和文字。

画面：1:1 方图，正面平视，头部居中，从发顶取景到锁骨。
背景：浅灰色无缝棚拍背景。
光线：柔和的窗光从侧前方约 30 度照来，脸颊、颧骨下方、鼻翼旁和下颌下方保留柔和但清楚的明暗过渡。
色调：中性、真实的肤色，不偏暖也不偏冷；脸颊、鼻头、耳朵和嘴唇保留自然血色。
造型：{按用户的选择，比如：发型和妆容按参考图，刘海微微分开，两只眼睛和眉毛完整露出}。
真实感：左右眉峰、眼睑折痕和嘴角有很轻微的自然差异；鼻翼沟、鼻唇沟和人中保留自然起伏，不要把中面部抹平。
皮肤：干净的真实照片肤质，自然肤色，不磨皮、不美白；适度减弱油光，保留轻微的自然高光。
服装：脖子和锁骨裸露，画面里不出现任何衣服、肩带、领口、项链或配饰。
表情：自然放松的中性表情，嘴唇轻轻闭合。
不要文字和水印。避免完美无瑕的合成 AI 脸，保留真实的人类细节。
```

用户确认这张就是她之后，再出下面的锁定图。出锁定图时，基准脸放在第一张参考图，原始参考图放在后面；提示词第一段改成"第一张参考图是她的正面基准照，后面的参考图是同一个人，长相以第一张为准"。

## 2×2 锁定图：妆发版（生产用）

```text
生成一张真人照片质感的身份参考图，像用定焦人像镜头在同一次棚拍里拍下的四个角度，未经后期精修。附带的参考图都是同一位成年女性，她的长相、发型和妆容完全以参考图为准；只取参考图前景里的这个人，忽略屏幕、其他人和文字。

画面：1:1 方图，平均分成 2×2 四个格子。左上正面，右上 45 度斜侧，左下严格 90 度正侧面，右下背面。四个格子是同一个人，每格头部居中、大小一致，从发顶取景到锁骨。格子之间不画分割线、边框或留白。
背景：整张图是同一种连续的浅灰色无缝棚拍背景。
光线：柔和的窗光从侧前方约 30 度照来，脸颊、颧骨下方、鼻翼旁和下颌下方保留柔和但清楚的明暗过渡；四格光线一致。
色调：中性、真实的肤色，不偏暖也不偏冷；脸颊、鼻头、耳朵和嘴唇保留自然血色。
造型：发型和妆容按参考图。刘海微微分开，两只眼睛和两条眉毛完整露出；背面那格展示头发的长度和层次，长发被画面自然截断。
真实感：左右眉峰、眼睑折痕和嘴角有很轻微的自然差异；鼻翼沟、鼻唇沟和人中保留自然起伏，不要把中面部抹平。
皮肤：干净的真实照片肤质，自然肤色，不磨皮、不美白；适度减弱油光，保留轻微的自然高光。
服装：脖子和锁骨裸露，画面里不出现任何衣服、肩带、领口、项链或配饰。
表情：四个视角都是自然放松的中性表情，嘴唇轻轻闭合。
不要文字和水印。避免完美无瑕的合成 AI 脸，保留真实的人类细节。
```

## 2×2 锁定图：素颜盘发版（核验骨相用）

和妆发版相同，只换"造型"一行：

```text
造型：素颜状态，几乎没有妆容：不上眼线、不涂睫毛膏、不上口红，只保留自然的唇色与健康血色；脸颊不扫腮红；不磨皮、不美白、不修容。黑色长发向后梳顺，盘成低发髻，额头、发际线、两只耳朵和下颌线完全露出；背面那格展示发髻。
```

GPT Image 默认会给妆感，素颜那一句要写完整，不要缩成"素颜，不化妆"。

## 出图后还不对

一次只改一处，再生成一次，才知道是哪一处起了作用。

| 症状 | 处理 |
|---|---|
| 四格不是同一个人，或不像参考图 | 先加参考图：同一个人的参考图越多越准。不要用文字补五官描述 |
| 背景不是浅灰 | 检查"背景"一行还在不在；在的话把颜色写得更具体 |
| 出现分割线、边框 | "画面"一行后面补"整张图是一个连续的画面" |
| 出现衣服、肩带、项链 | 检查"服装"一行；仍出现就用 `grid_tools.py split --keep` 裁掉 |
| 素颜版有妆感 | 确认用的是完整的素颜段 |
| 皮肤像磨皮、塑料、没有阴影 | 检查光线有没有被改成均匀平光；按画质与真人感的排查顺序查 |
| 画面脏、有噪点、蜡质 | 先删掉细节、纹理类的词；还脏就加去噪段（见画质与真人感） |
| 脸太完美、太对称 | 确认"真实感"一行和最后的反向锁定都在 |
| 侧面那格崩坏 | 参考图里没有这个角度，补一张有侧脸的参考；没有就把这格标为推断 |

## 尺寸和像素

请求 2048×2048 或模型支持的最大 1:1 尺寸，但 GPT Image 实际常只出 1.2～1.6MP，2×2 每格只剩几百像素。锁定图用来判骨相和多视角一致性；判肤质看基准脸那张单图。记录里写实际输出像素。

## 张数

默认一次出 1 张。用户要抽卡时再一次出多张横向比较，不要在一张上反复改措辞。

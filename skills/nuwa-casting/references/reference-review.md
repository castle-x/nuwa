# 参考图评审

参考图决定了锁定图的上限。参考图里看不清的东西，模型只能现编；现编的部分，每次生成都不一样。所以写提示词之前，先评审参考图，判断它们够不够出一张锁定图。

## 逐张打分

每张参考图按下面六项检查，每项记"好 / 一般 / 差"：

| 项 | 好 | 差 |
|---|---|---|
| 脸的清晰度 | 脸在图里够大（脸部高度占图片高度的四分之一以上），对焦清楚 | 脸很小、虚焦、动态模糊、压缩严重 |
| 光线 | 光线均匀，五官的明暗都看得清 | 暗光、闪光灯直打、强逆光、大面积阴影 |
| 遮挡 | 眉毛、眼睛、鼻子、嘴、下颌都露出来 | 头发、手、眼镜、口罩挡住五官或下颌 |
| 角度 | 头部端正，能明确说出是正面、45° 还是侧面 | 大幅歪头、仰拍俯拍、极端透视 |
| 表情和妆容 | 表情自然放松，妆容清淡，能看出骨相 | 夸张表情，浓妆、滤镜、美颜改变了脸型 |
| 写实程度 | 真实照片质感 | 插画、强风格化，或者明显的 AI 痕迹 |

再看整组：

- **是不是同一个人**：多张参考之间五官对得上吗？对不上的要剔除，否则模型会把几张脸平均成一张。
- **角度覆盖**：锁定图要正面、45°、90° 侧面、背面。哪些角度有清楚的参考，哪些只能靠模型推断？

## 四层拆解

每张参考图按同一顺序看一遍，先写看到的事实，再写你的判断：

| 层 | 看什么 |
|---|---|
| 骨相与轮廓 | 脸型长宽比、额头饱满度、颧骨高低与外扩、下颌角转折、下巴形态、头肩比例、颈长 |
| 五官形态与分布 | 三庭五眼比例、眉形与眉峰、眼型与眼尾方向、眼睑结构、鼻梁与鼻尖、唇厚与唇峰 |
| 原生质感与妆造 | 肤色调性、毛发质感、发型对脸型的修饰、妆容浓淡 |
| 拍摄光影与氛围 | 焦段透视、光线冷暖与软硬、表情状态、有没有后期痕迹 |

## 干扰项

这些特征会被模型当成目标结构复现出来，评审时要点出来：

- 手机前置或广角镜头造成的鼻子放大、脸型拉长
- 强滤镜造成的皮肤均匀化、五官边缘锐化
- 重度美颜造成的下颌收窄、眼睑加宽
- 头发、手、道具对颧骨和下颌的遮挡
- 单侧阴影被误读成骨相凹陷
- 截图压缩造成的色块和噪点

## 多个人的参考图融合

上面"同一个人的参考图默认全部上传"只适用于同一个人。要从几个不同的人身上取特征、融成一张新脸时，规则相反：

- **每张图只负责一个部位**：定轮廓、定眉眼、定神态、定质感，或者只作风格参考。不要让两张图同时定同一个部位，那必然平均成一张谁都不像的脸。
- **先查特征兼容性**：几套特征放在同一张脸上讲不讲得通。常见冲突：浓颜五官（大眼、厚唇、高鼻）配极窄的幼态颌面；极短中庭的少年感配明显外扩的颧骨；下颌角分明配极尖且前突的下巴；低平的山根配极高的鼻梁转折。遇到冲突不要自己折中，把冲突指出来，给两个收敛方向让用户选。

## 给每张定职责

同一个人的参考图越多，人脸还原越准，所以默认全部上传，评审只用来排顺序、定职责、判断角度覆盖。质量一般的图也能补充信息，不要因为不够清楚就剔掉；只剔除不是同一个人、或脸完全看不见的图。

| 结论 | 条件 | 用法 |
|---|---|---|
| 主身份图 | 清晰度、光线、遮挡三项都是"好"，最好接近正面 | 作为参考图 1 |
| 辅助图 | 有一两项"一般"，但能补充主身份图没有的角度或信息 | 作为后面的参考图，提示词里写明只负责什么 |
| 不用 | 不是同一个人，或者脸完全看不见 | 不上传 |

## 判断够不够

**够**：至少一张主身份图，并且正面、45° 两个角度都有清楚的参考。直接写锁定图提示词，同一个人的参考图全部上传，主身份图放在第一张。

**不够**（全都模糊、暗、遮挡多，或者缺关键角度）：

1. **补参考**：向用户要更清楚的图，说清楚缺什么，比如"缺一张光线均匀的正面"或"缺一张正侧面"。
2. **补不了，就用基准脸找感觉**：直接进入"出正面基准脸"，多出几张，让用户挑出最接近心目中样子的那一张，确认后再出锁定图。

不管够不够，定脸都要先出正面基准脸、用户确认后再出锁定图。参考图足够多、足够清楚时，评审可以从简。

## 评审结果写进档案

写进这个模特的参考证据文件：每张图的六项打分、职责、整组的角度覆盖、够不够的结论和选择的路线。下次换模型、重出锁定图时，直接沿用这份评审。

# 妆容复刻与修复：腮红、唇釉与光泽肤质

用户要求明显的腮红、唇釉、高光、皮肤反光或偏冷白的细腻肤质时读这一篇。这是可选风格；用户要自然肤质时，回到 [画质与真人感](realism.md) 的默认写法。

## 先分析，再转文字

妆造示例图只用来观察，不当参考图上传（避免把示例里那个人的脸带进来）。分区观察后转成文字：

1. 腮红：颜色、位置、扩散范围、浓度、边缘。分别看颧骨、眼下、鼻梁与鼻尖。
2. 唇部：底色、透明度、覆盖程度、唇线、唇纹、反光。唇釉要有可见的湿润膜感和局部亮点。
3. 高光：额头、颧骨、鼻梁、鼻尖、人中、唇峰的实际反光分布。
4. 皮肤：肤色、底妆覆盖、纹理粗细、光泽强度、高光过渡。
5. 眼妆：眼影色调、眼线粗细与长度、睫毛密度、下眼睑颜色、眉毛质感。
6. 身份：明确保留角色的五官和骨骼轮廓。

## 按症状修

每次只调整用户指出的那一处，并完整保存实际提交的原文。

| 症状 | 处理 |
|---|---|
| 腮红不明显 | 明确增加目标区域的色彩浓度与范围 |
| 唇釉感不足 | 明确湿润薄膜、透明饱和色和下唇局部高光 |
| 面部太哑光 | 明确颧骨、鼻梁、鼻尖的可见反光与渐变 |
| 皮肤显粗糙 | 减轻粗颗粒与夸张斑点，保留细小毛孔 |
| 出现塑料感 | 恢复局部皮肤纹理与自然反光过渡，检查高光是否过曝 |

## 验收

腮红有明确位置和柔和边缘；唇釉有局部反光和真实唇部结构；鼻梁和颧骨有可见反光，同时高光内部保留细节；五官比例和年龄仍与身份图一致；皮肤保留真实纹理和自然血色。

# 选角与定角色

脸是一个模特最不能漂的东西。后面每一环（穿衣、换景、生视频）都会拿这一环的产出当身份依据，所以这一环交出去的东西要满足下游的使用条件，而不只是"这张脸好看"。

判断一张脸成不成立，看它放大后有没有真实的皮肤表面、换角度后骨相是否自洽、多次生成是否真是同一个人，而不是看第一眼好不好看。

## 流程

```text
问用途与造型 → 评审参考图 → 出正面基准脸 → 用户确认 → 出 2×2 面部锁定图 → 核验 → 定稿锁定
                    │            （GPT Image）    │ 不像就重出
                    └─ 参考很差：先补参考，或直接用基准脸找感觉
```

核心思路：**先把一张正面脸定下来，再出多视图。** 直接从参考图出四视图，模型要同时猜长相和猜角度；先定一张用户认可的正面基准脸，长相就固定了，出多视图时模型只需要转角度。

### 1. 问用途与造型

一次只推进最关键的一两个决定，不要抛问卷：

- 这个模特在哪出现（穿搭账号、写真、剧情），第一眼是什么气质和年龄感，最想保留什么记忆点，最反感哪些 AI 痕迹。
- 参考图里的发型、妆容要保留还是调整（可以分别选）。
- 带表情，还是无明显表情、偏证件照的感觉。默认无明显表情。
- 皮肤高光保留参考图的光泽，还是适度减弱油亮反光。

用户说不清时，给两三组反差鲜明的骨相和气质方向让他凭直觉挑，或者直接要参考图。结论写进档案的需求边界，写法见 [需求边界](references/brief.md)。需要从几个人的参考里融出一张新脸时，再写一份 [设计方案](references/treatment.md)，定下三到五个识别锚点。

### 2. 评审参考图

参考图决定了锁定图的上限：参考图里看不清的地方，模型只能现编，每次生成都不一样。写提示词之前先评审，这一步是门槛。

1. **逐张打分**：脸的清晰度、光线、遮挡、角度、表情和妆容、写实程度。
2. **看整组**：是不是同一个人；正面、45°、侧面、背面，哪些角度有清楚的参考。
3. **定职责**：主身份图、辅助图、不用。
4. **判断够不够**：至少一张清楚的主身份图，并且正面和 45° 都有参考，才算够。

同一个人的参考图默认全部上传，参考越多人脸越准；评审只用来排顺序、判断角度覆盖，不用来删图。

参考图很差（全都模糊、暗、遮挡多）时，先告诉用户缺什么，问能不能补；补不了，就直接进入下一步，用基准脸来找感觉。参考图足够多、足够清楚时，评审可以从简。

每张图还要拆成四层说给用户听：骨相轮廓、五官分布、原生肤质、拍摄光影，并确认这张图定的是轮廓、眉眼还是神态。

评分标准、四层拆解、干扰项、多人融合的规则和各条路线的做法见 [参考图评审](references/reference-review.md)。

### 3. 出正面基准脸

先用 GPT Image 出一张正面头肩照，作为这个模特的基准脸：

- **输入**：同一个人的全部参考图，最清楚的正脸放第一张。
- **要求**：正面平视、头发不遮脸、光线均匀、浅灰背景、不出现衣服。造型（发型、妆容）按用户在第 1 步的选择。
- **和用户比对**：拿基准脸和参考图对照，用户确认"这就是她"才往下走；不像就调整参考图顺序、补参考或改文字后从原始参考图重出，不要把这张基准脸再喂回 GPT Image 一轮轮修改。

提示词模板见 [面部锁定图提示词](references/face-lock-prompt.md) 的"基准脸"一节。

参考图很差时，这一步就是"找感觉"：多出几张，让用户挑出最接近心目中样子的那一张。

### 4. 出 2×2 面部锁定图

以确认过的基准脸为主身份图出锁定图：

- **输入**：基准脸放第一张，原始参考图放在后面补充角度和发型细节。
- **这是一次正常的成图交接**：基准脸是 GPT Image 的成图，用户确认后作为下一步的参考图喂回 GPT Image 一次，属于允许的"定稿往下传"。
- **不在锁定图上迭代**：锁定图不满意，回到基准脸和原始参考图重出，不要把锁定图再喂回去改；局部小修（去一缕碎发、改一处妆）交给 Nano Banana Pro。
- **来源写清楚**：角色锁定设定里写明基准脸是哪次生成的、用了哪些参考图、锁定图是第几次回喂。

成图回喂的完整规则见 [参考分工](../nuwa/references/reference-roles.md) 的"选模型与成图回喂"。

## 每次生成都适用

基准脸和锁定图每次生成，都按下面四项来。

### 选模型

问清用户能用哪些生图模型，再查 [模型能力速查表](../nuwa/references/model-capabilities.md)：

- **用户丢进来的原始参考图，第一次出图就用 GPT Image。** 不管是截图、网图还是用户自己拍的，来源不影响这条。基准脸和面部锁定图都首选它，从参考图直接生成，身份还原度最高。
- **尽量少把 GPT Image 的成图再喂给 GPT Image。** 用户确认过的定稿往下传一步（基准脸 → 锁定图）可以；同一张成图反复修改不行，面部会被一轮轮重绘。
- **局部编辑交给 Nano Banana Pro**（换发型、去妆、去碎发）。直接用它从参考图出多视图随机性大，同一提示词两次可能不是同一个人。
- 用户坚持要在 GPT Image 的成图上再改时，先提醒风险，再照做，并在记录里写明第几次回喂。
- 真实感的上限由有效分辨率决定。1MP 左右的输出判断不了"够不够真"，定稿要用 2K 以上的输出。
- 真实感的上限由有效分辨率决定。1MP 左右的输出判断不了"够不够真"，定稿要用 2K 以上的输出。

### 写提示词

**模板不等于当前任务。** 文档里的提示词示例、别的模特的正本，参考图数量和身份段都属于那一次任务。手上在做某个模特时，参考组和身份段不换，只借构图、背景、光线这些通用段。用户拿一份模板来"录进技能"时，录入和出图是两件事，不要顺手拿模板的参考组出图。

**先定脸，再做造型。** 锁定图（尤其是素颜盘发版）的任务是判断骨相和身份成不成立，看着"没那么好看"是正常的；好不好看由穿衣合成和定妆负责。顺序反了，会一直在造型层反复改，改不到根上。

**人脸交给参考图，其余维度用文字锁死。**

- **人脸不用文字描述。** 参考图给够了，脸的细节就交给参考图。脸很难用文字描述准确，写多了反而会和参考图抢话语权。用户认可过的提示词原文逐字复用，不要因为里面有面部描述就改写。
- **其他维度都要写清楚**：格位与视角、构图、背景、光线、发型妆容、服装、表情。参考图给不了这些，不写模型就自己定，比如不写背景可能出纯黑背景。
- **真人感要求要写。** 拍摄语境（定焦人像镜头、未经精修的原片）、有明暗过渡的光线、中性色调、轻微的自然不对称、不抹平中面部、干净的照片肤质、最后一句反向锁定。这些和长相无关，有参考图时也要写，详见 [画质与真人感](references/realism.md)。
- **按模型调整肤质写法。** GPT Image 要干净，不写细节、颗粒、微阴影这类词，否则会变成噪点和脏灰调；Nano Banana 系列反而适合用具体的细节词。
- **表情**默认写"四个视角都是自然放松的中性表情，嘴唇轻轻闭合"。用户要表情时，确认具体表情后替换。
- **用户选择减弱油光时**，写"适度减弱油光，保留自然的皮肤纹理和轻微高光"。
- **提示词默认用中文写。** 模型或使用者需要英文时再翻译。

模板和出图后的处理见 [面部锁定图提示词](references/face-lock-prompt.md)。

### 生成前确认

调用生图接口前，把这些交给用户确认：模型和通道、尺寸、张数（默认 1 张）、提示词原文、每张参考图及其职责和来源（成图要写明是第几次回喂）。改一个字都要重新确认。用户明确说"直接生成"只对这一次有效。

可以用确认单脚本出一张自包含的确认页，用户点确认后下载回执，出图前核对回执，见 [生成前确认](../nuwa/references/confirm-before-generate.md)。

### 核验

- **GPT Image 专项**：放大看是干净皮肤还是均匀颗粒和脏灰调；中面部有没有被填平（鼻翼到脸颊连成一片亮面）；刘海、眼睑高度、唇厚有没有漂回模型默认值。
- **按用途看像素**：2×2 锁定图每格只有几百像素，只判骨相和一致性；肤质看基准脸那张单图。记录写实际输出像素。
- 放大到同一尺寸看皮肤：有没有真实的毛孔和细小色差，还是一片平滑。
- 看多个视角：骨相、眼距、鼻梁走势、下颌是否自洽，是不是同一个人。
- 看表情：是否符合选择，嘴唇是否闭合，嘴角和眉眼是否一致。
- **多视角检查点**：鼻梁与额头的夹角在正面和侧面是否对得上；下颌角在 45° 和侧面的转折是否同一条线；耳朵位置在侧面是否和正面的眼鼻高度对应；背面的发际线和发量是否和正面一致。
- **测像素，不估像素**：用脚本读实际输出尺寸，每格的像素按网格算出来写进记录。
- 说一张图成立之前，先按上面几项自己核过。

## 收尾

### 5. 分层迭代

按这个顺序收敛：整体像不像活人 → 轮廓骨相 → 眉眼神态 → 鼻唇细节 → 肤质光影 → 多角度一致性。用户说"不如前面那批"时，先回到那批的提示词原文做对比，不要凭印象重写。

修改时回到原始参考图和已确认的基准脸，改文字要求重新生成；不要把同一张成图一轮轮喂回去改，细节会越改越少，骨相会越来越像"平均脸"。局部问题用 Nano Banana Pro 改。

每轮怎么判断、怎么只改一层、怎么记录，见 [分层迭代](references/iterate.md)。发型和妆容的写法见 [妆容](references/makeup.md)。

### 6. 定稿锁定

用户认可后，写角色锁定设定，放进档案的 `角色锁定.md`。字段和写法见 [角色锁定设定](references/character-lock.md)，至少要有：基准脸和身份图的路径、生成模型和提示词原文、每次成图回喂的记录、不可漂移项与可变项、用户确认的原话。

**已有角色不要重新造。** 用户要给已经定稿的模特出新图时，从 `角色锁定.md` 取身份图和提示词，不要从参考图重新走一遍定脸。

之后所有环节都从这里取身份图，不要用某次视频的截图或某张合成图代替身份图。

## 面部锁定图

面部锁定图是这个模特身份的唯一依据，后面每一环都会把它当参考图上传。规格按"上传给任何模型都能用"来定：

| 项 | 规格 | 原因 |
|---|---|---|
| 画布 | 1:1 方图，2×2 四格，每格也是 1:1；整张 2048×2048 以上 | 1:1 几乎所有生图、生视频模型都接受；四格各自裁出来仍是 1:1，可以单独上传。一行三格的横图，每格是瘦长条，整张和单格都不是标准比例 |
| 四个视角 | 左上正面，右上 45° 斜侧，左下 90° 正侧，右下背面 | 45° 是视频里最常出现的角度；背面让转身时后脑和发型有依据，不用模型现编 |
| 构图 | 每格头部居中、大小一致，从头顶到锁骨 | 四格的头一样大，才能互相对照骨相 |
| 不露服装 | 脖子和锁骨裸露，画面里不出现任何衣服、肩带、领口、项链、配饰 | 衣服会被当成"这个人的一部分"迁移到后面的图里，而且每次生成都随机 |
| 不画分割线 | 四格之间没有线、边框或留白，整张是连续的同一种浅灰背景 | 分割线会让模型把参考图读成拼贴或分屏，更容易生成多个人；切图按四等分的几何位置切，不需要线 |
| 表情 | 中性放松，嘴唇闭合 | 带笑的身份图会让后面每张图都带着同一个笑 |

提示词模板见 [面部锁定图提示词](references/face-lock-prompt.md)。

生成后用脚本切成四张单独的 1:1 图，需要时顺手裁掉底部露出的衣服：

```bash
python3 <skill>/scripts/grid_tools.py split 面部锁定图.png
python3 <skill>/scripts/grid_tools.py split 面部锁定图.png --keep 0.85
```

`--keep 0.85` 表示每格只保留上面 85%，用来去掉锁骨以下意外出现的衣服；左右会等量收窄，切出来仍是 1:1。切出的文件按视角命名：`-正面`、`-45度`、`-侧面`、`-背面`。

## 交给下游的规格

| 产出 | 要求 | 给谁用 |
|---|---|---|
| 面部锁定图（2×2 四视图） | 见上一节 | 穿衣合成的模特参考图；视频生成的身份参考 |
| 四张单视角图 | 从锁定图切出，各 1:1 | 只能传一张图、或要对齐某个视角时单独使用 |
| 角色锁定设定 | 见"定稿锁定" | 所有后续环节 |

几个容易被忽略的要求：

- **表情要中性。** 带笑的身份图会让后面每一张图、每一段视频都带着同一个笑。需要表情时在动作阶段用文字加。
- **发型要定下来。** 身份图里的发型会被当成"这个人的一部分"迁移。打算换发型，就在这一环出不同发型的版本，或在锁定设定里写明发型是可变项。
- **头发不要遮脸。** 碎发挡住眼睛或脸颊时，后续视频里模型每帧都要重建被遮住的部分，容易漂。至少要有一个视角能完整看清五官。
- **背景要纯净。** 身份图的背景会被一起迁移，后面再换场景会更难。

## 常见问题

| 现象 | 处理 |
|---|---|
| 后续视频里脸逐帧漂移 | 多半不是这一环的问题，先看 `nuwa-polish`。如果身份图本身脸太小、太糊，回来补一张高清正面头肩照 |
| 四格被生成成不同的人 | 提示词写明"同一个人的四个视角"并逐格写清视角，核验四格的骨相是否一致 |
| 锁定图里出现衣服或肩带 | 提示词写明脖子和锁骨裸露、不出现任何衣物；仍出现时用 `--keep` 裁掉底部 |
| 四格之间出现白线或边框 | 提示词写明不画分割线、背景连续；已经出现时切图后各格边缘会带线，重新生成 |
| 皮肤像磨过皮、没有阴影 | 去掉压低阴影和正面平光的写法，改用有方向的窗光，见速查表"写实人脸" |
| 皮肤油亮 | 用上面的减弱油光句 |
| 侧面那格崩坏 | 参考图里没有这个角度，模型只能推断。补一张有侧脸的外部参考；没有时把侧面格标为推断，视频里避开纯侧脸 |
| 两次生成不是同一个人 | 模型随机性大，或参考图太少、太暗、遮挡多。先回到参考图评审，确认参考够不够；再考虑多抽几次比对或换 GPT Image |
| 要求素颜却带了妆 | 有的模型（如 Seedream）会做成伪素颜。换模型，或写明不打粉底、保留雀斑和肤色不均 |
| 多张参考融合成了"平均脸" | 减少参考图数量，或者明确每张图只负责哪一层 |

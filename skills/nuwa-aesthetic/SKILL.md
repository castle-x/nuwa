# 概念写真：视觉美学方法论

一张让人停下来的照片，分两层：

- **执行标准**：构图、对焦、光线、姿态都做到位。这是底线，做不到画面就不成立，但做到了也只是「拍得不错」。
- **记忆点**：画面里有一个让人想多看一眼的设计，通常是一处反差或冲突。抓人的是这一层。

这个分支讲的是第二层怎么设计、怎么拆、怎么组合，以及怎么把它写成模型执行得了的提示词。具体案例见 [示例](references/examples.md)。

公共规则见 `nuwa`；画面里有场景时，场景卡的整理方法见 `nuwa-set`。

## 四个通用工具

### 1. 反差：只要一个主反差

记忆点大多来自「两样不该在一起的东西出现在一起」。常见的反差维度：

| 维度 | 例子 |
|---|---|
| 身份 × 物件 | 日常装扮 × 一件来自另一个世界的道具（宇航头盔、潜水头盔、古董面具） |
| 场景处境 × 场景状态 | 被废弃的地方 × 干净有序的内部 |
| 色彩 | 大面积单一色调 × 一小处反色 |
| 尺度 | 很小的人 × 巨大的空间或物件 |
| 动 × 静 | 安静的画面 × 一处正在发生的动作（飘起的纱帘、溅起的水） |
| 时代 | 复古的空间 × 未来的物件，或反过来 |

规则：

- **一张图只有一个主反差。** 其他维度可以叠加，但要服务于它。主反差有两个以上，画面就乱了，观众不知道该看哪里。
- **反差物件只放一个。** 日常装扮配一个异质道具成立，配三个就成了 cosplay 合影。
- **其余元素要安静。** 主反差之外的服装、场景、道具都往「日常」「朴素」「有秩序」靠，让反差更突出。

### 2. 焦点合一：把所有注意力压在同一个点上

只有反差，画面还只是一个「梗」。要把它做成好照片，就让下面几样**落在同一个位置**：

- 叙事上的反差点（那件异质道具、那个不该出现的动作）
- 对焦点
- 画面里最亮或唯一不同颜色的光
- 构图上视线被引导去的位置

四样都落在一处时，观众的眼睛会直接被吸过去。设计时先问一句：这张图的那个点在哪？然后检查对焦、光、色、构图是不是都指向它。

### 3. 底色统一：先让底色足够统一，反色才会跳出来

色彩反差靠的不只是那一处反色够亮，更靠底色够统一：

- 主色铺满画面，大约九成以上面积。
- **画面里所有中性色（白墙、白窗帘、白衣服、灰色家具）都要染上主色调。** 任何一块中性白都会稀释反差。
- 反色只出现在焦点那一处，而且最好是光，而不是一块颜料。光有亮度，比单纯的颜色更跳。
- 写清反色是怎么来的：光源本身是什么颜色、照在什么东西上、受光物（皮肤、头发、金属）把它染成了什么颜色。不写来源，模型会自己补，往往会把暖色撒得到处都是。
- 人物的发色、服装颜色也会参与配色。想要的反色点很小时，人物身上大面积的颜色要和底色一致，否则会抢走反色。

### 4. 空间引导：用前景、纵深和机位把眼睛送到焦点

- **前景当画框。** 一块离镜头很近、完全虚掉的物体（桌面、门框、植物、玻璃）压在画面边缘，既有纵深，又把视线往里推。光面的前景还会映出主体的倒影，多一层呼应。
- **纵深层次。** 近处虚、中间有遮挡、远处是清晰的主体，三层由近到远排开。
- **机位高度决定气质。** 低机位贴着物体拍，画面安静、有窥视感；平视显得日常；俯拍显得疏离。
- **留空间。** 主体不必占满画面。人物小一点、四周留空，冷清、孤独的情绪更强。

## 对标拆解：先拆清楚，再动手写

有参考图时，按这五层逐层读出来，每层都写成能对照检查的句子：

1. **概念**：主反差是什么，焦点合一落在哪一点。
2. **色彩**：主色、反色、反色的来源，以及画面里有没有中性白。
3. **光**：光从哪来、软硬、反差，背景比人物亮还是暗。
4. **空间**：画幅、机位高度、机位朝向、前景是什么、人物在画面里的上下边界。
5. **人物**：坐、站、蹲、躺哪一种，身体朝哪个方向，脸朝哪个方向，视线落在哪里，手在干什么。

用户凭记忆描述一张图时，下面这些地方最容易和原图对不上，拆的时候要逐一核对，不确定就请用户给原图：

| 容易偏的地方 | 常见偏差 |
|---|---|
| 画幅 | 记成 9:16，实际是 2:3 或 3:4 |
| 机位 | 记成「平视」「对角线」，实际是贴着某个物体的低机位，几乎正对主体 |
| 前景 | 只记得「有点虚」，实际是占画面三成的大块虚化加倒影 |
| 姿态受力 | 「蹲」和「坐着抱膝」在描述里差不多，在画面里差很多；屁股是落在椅面上，还是悬空 |
| 身体方向 | 记得脸朝镜头，没注意身体其实侧着 |
| 色彩来源 | 以为某块颜色是物体本身的颜色，实际是光照出来的 |
| 物料 | 桌布还是光面桌面、过膝袜还是整条裤袜，会改变画面的质感和反光 |

## 把感觉翻译成模型执行得了的描述

景别、焦距这类摄影术语，用户和模型都容易理解偏。改成看得见的相对关系：

- **机位高度**：写镜头「贴着什么东西」「和人物的哪个部位一样高」，不只写「低机位」。
- **景别**：写人物在画面里的上下边界，例如「头顶在画面高度约 17% 处，脚在约 70% 处」，不只写「中景」「全景」。
- **距离和焦距感**：写镜头离人物几米、前景离镜头多近，再配一个焦距和光圈。
- **身体方向**：按画面方位写，「身体朝画面左侧转约 45 度，臀部露在画面右侧」，再单独写脸和视线朝哪里。身体和脸朝不同方向时，两件事都要写。
- **姿态受力**：写身体的重量落在哪里，「屁股坐在椅面上」「双脚踩在椅面前沿」，不写「蹲坐」这种两可的词。
- **色彩**：写「画面里所有白色都被染成浅青蓝色，没有中性白」，再写反色的来源和范围。

提示词按标准字段写，每个字段只放对应内容：优先级、人物、身材、皮肤、表情、姿态、服装、场景、光线、构图、相机参数、画面质感。优先级字段写这张图最不能错的两三件事，通常是机位、焦点和主反差。

## 排列组合：用槽位造新概念

把一张成立的图拆成槽位，换掉其中一两个，就是一个新概念：

| 槽位 | 问自己 |
|---|---|
| 主体身份 | 她平常是谁、穿什么（日常、朴素） |
| 异质元素 | 唯一那个不属于这里的东西是什么 |
| 场景 | 处境和状态之间有没有反差（废弃但干净、热闹的地方空无一人） |
| 色彩方案 | 主色是什么，反色是什么，反色由什么光源产生 |
| 焦点 | 反差点、对焦点、反色光是不是在同一处 |
| 空间 | 前景是什么，机位贴着什么，人物在画面里多大 |

组合时：

- **一次只换一两个槽位**，其余沿用已经成立的设定。全换掉就等于从零开始，成功率回到随机。
- 换完先用一句话说出这张图的点在哪里。一句话说不清，就是主反差不够明确。

## 流程

1. **定概念。** 有参考图就按「对标拆解」读五层；没有就从槽位出发，先写一句话的概念。
2. **写提示词。** 按标准字段写，机位、景别、方向、色彩都用上面的翻译方法写死。
3. **选模型出图。** 查 `nuwa` 的模型能力速查表。多个模型并行各出一版，对比哪个最接近。
4. **逐层对照。** 拿结果和参考图（或概念）按五层对照，先找最大的偏差。
5. **只改对应字段。** 在出问题的那个字段里替换原句，不往后追加补丁，一次只改一个变量。

## 人物与尺度

- 人物一律设定为成年人。参考里有「少女感」「萝莉」这类说法时，写成「成年女性，少女感造型」，保留造型气质，不改变年龄。
- 姿态和构图把注意力留在主反差上。低机位、抱膝坐这类构图容易让画面重心滑到腿和臀部，要在姿态和构图字段里写死遮挡关系和人物大小，避免模型自行加强身体暴露。

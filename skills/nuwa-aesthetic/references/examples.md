# 概念写真示例

每个示例按「拆解 → 槽位 → 提示词 → 复用时注意」写。示例是方法论的一次应用，换概念时只沿用方法，不照搬具体的冷暖和人物设定。

## 示例一：废弃餐车里的宇航头盔

### 拆解

| 层 | 内容 |
|---|---|
| 概念 | 主反差是身份 × 物件：日常体操服配一顶真实的飞行员头盔。焦点合一落在头盔里那张被暖光照亮的脸上 |
| 色彩 | 主色是偏蓝的青色，窗帘、上衣、裤袜这些白色全被染成浅青蓝；反色是头盔内部的暖橙光，来源是头盔内沿的白色灯带，照在皮肤和刘海上变成暖橙色 |
| 光 | 冷色天光从车窗和薄纱窗帘漫射进来，没有直射，反差低 |
| 空间 | 2:3 竖幅；低机位，镜头贴着近处一张光面桌面，几乎正对人物；近处桌面占画面下方约三成，完全虚化并映出头盔暖光的倒影；中间一张餐桌横过画面，挡住小腿 |
| 人物 | 侧身坐在卡座长椅上抱膝：身体朝画面左侧转约 45 度，小腿向画面左下方斜伸；肩膀和头转回来对着镜头，眼睛微微向上看；双手托着头盔下沿 |

### 槽位

| 槽位 | 本例 |
|---|---|
| 主体身份 | 成年女性，日漫 cosplay 造型，日式体操服、白色裤袜 |
| 异质元素 | 真实质感的旧飞行员头盔 |
| 场景 | 废弃的老式火车餐车，内部干净 |
| 色彩方案 | 青蓝底色 × 头盔里一处暖橙光 |
| 焦点 | 头盔里的眼睛 |
| 空间 | 前景光面桌面虚化加倒影，人物在画面中部偏小 |

### 提示词（Seedream 5.0 Pro）

不带参数，比例在生成界面选 2:3。

```text
优先级：机位高度和前景虚化最重要，其次是侧身坐姿，再次是冷暖对比。

人物：一位成年日本女性，日漫 cosplay 风格造型，深棕偏黑的长发，厚重齐刘海，两侧长发垂到胸前。头上戴着一顶真实质感的白色飞行员头盔，外壳有些旧，画面右侧挂着一根黑色波纹软管。头盔压得比较低，下沿在嘴巴的位置，面罩是打开的，露出眼睛和鼻子。

身材：身形纤细，腿型修长。

皮肤：皮肤保留自然纹理，面部没有油光反光。

表情：神情安静、出神，脸正对镜头，眼睛微微向上看，视线落在镜头上方。

姿态：她侧着身子坐在卡座长椅上，身体朝画面左侧转约 45 度，臀部和短裤露在画面右侧。两条腿屈起并拢抱在身前，膝盖朝画面左前方，小腿向画面左下方斜伸，双脚落在画面左下。肩膀和头转回来朝向镜头，两只手抬到脸的两侧，托着头盔下沿。

服装：日式体操服，白色短袖上衣，领口和袖口有深蓝色滚边，深蓝色短裤，腿上穿一整条白色裤袜，表面有柔和的光泽。

场景：一节老旧的火车餐车车厢，车厢干净整洁。她坐在靠窗的卡座里，卡座是深色边框和灰绿色坐垫。她面前是一张光面金属餐桌，只有一根中间的独立桌腿，桌面没有桌布。画面左侧有一扇车窗，窗外是模糊的绿色树林。画面右侧挂着大幅白色半透明薄纱窗帘。画面里只有她一个人。

光线：冷色天光从车窗和薄纱窗帘漫射进来，没有直射阳光，光线柔和。整个画面统一成偏蓝的青色调，白色的窗帘、上衣和裤袜都被染成浅青蓝色，画面里没有中性白。头盔内沿有一圈白色细灯带，头盔内部被暖橙色光充满，照亮她的额头、刘海和眼周，刘海被染成橙色。这一团暖橙光是全画面唯一的暖色，头盔外壳和其余一切都是冷色。

构图：竖幅 2:3，全景。机位很低，镜头贴着近处一张光面桌面，大约在人物膝盖的高度，几乎正对着人物，微微向上拍。近处桌面占据画面下方约 30%，完全虚化，桌面上映出头盔暖光的模糊倒影。中间那张餐桌的桌面从画面中部斜着横过去，挡住她的小腿。人物在画面水平正中，头盔顶部在画面高度约 17% 处，脚在约 70% 处，四周留有空间。

相机参数：85mm 焦距，光圈 f/1.4，距离人物约 3 米，焦点落在头盔里的眼睛上，前景桌面强烈虚化，背景的窗帘和车窗轻微柔化。

画面质感：写实人像摄影，轻微胶片颗粒，冷暖反差强烈，整体氛围清冷、寂静。不要文字、水印。
```

复用时注意：

- 这段在 Seedream 5.0 Pro 上姿态和人物与环境的关系最准。Seedream 5.5 写实但人物会被拉近、被中间的桌子切碎；GPT Image 细节最多，但会把短裤画短、让腿和臀部占据画面，注意力从头盔跑到身体上。
- 刘海容易整片变橙。要求只剩几缕时，在 Seedream 5.5 上做局部编辑，比整张重出稳。
- 换概念时沿用「优先级、光线、构图、相机参数」四个字段的写法，替换「人物、服装、场景」三个字段里的槽位内容。
- 换成暖底冷点（比如暖黄室内里一处冷蓝屏幕光）时，同样要写「画面里所有白色都被染成暖色」，再写冷光的来源。

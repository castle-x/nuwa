# 场景配方

每个配方注明适用的模型。

## 棚拍工作花絮（Wan 3.0）

用手机在主摄旁边记录模特的棚拍过程。真实感来自三样东西：画面边缘的器材、手持的轻微晃动、模特不看手机镜头。

```text
竖屏 3:4，手机手持拍摄的摄影棚工作花絮，一镜到底。
场景：浅灰色无缝背景纸，墙面与地面弧形过渡。画面左侧边缘露出银色反光伞和灯架，右下角露出灯架轮子。画面里只有模特一个人，没有相机、手或其他人。
机位：手机在主摄旁边，几乎正面，腰部高度略微仰拍，人物居中全身，头顶留出空间，轻微手持晃动。
```

注意：画面边缘仍可能出现手臂，生成后要检查；姿势要写出换重心或换脚，否则变化不明显。

## 浅灰无缝棚

最干净的场景，适合定妆、三视图、舞蹈复刻。

```text
浅灰色无缝墙背景，没有其他人、器材、字幕、文字或水印。
```

## 中式地下停车场（Seedream 出空镜，Wan 3.0 出视频）

舞蹈和走位类短视频用，空镜一张即用。对标是一张真实的停车场跳舞截图。

```text
场景：商场地下停车场。画面左侧近处一根方形承重柱，柱身刷成粉色，朝向镜头的一面印着白色大号编号「B12」，柱子四条棱角从地面向上约 1.5 米贴着黄黑相间的箭头形反光条。中景两侧车位停着一排真实的家用轿车和 SUV，车牌模糊看不清字。地面是浅灰色环氧地坪，干燥、带一点哑光光泽，画着白色斑马线和黄色导向线。天花板较低，裸露的管线和桥架整齐排列，一排排长条灯管亮着。画面里没有人。
光线：长条灯管从正上方均匀照下，整体明亮不刺眼，地坪上映出一条条柔和的长条反光。
构图：竖屏，正面平视，机位在成人胸口高度；柱子、车顶线、斑马线和天花板管线都汇聚到同一条视平线上。
```

要点：对标图里柱子上的点阵装饰不要；除编号「B12」外不要任何文字。人站在柱子右侧的空地上，离镜头约 3 米时全身约占画面高度一半。

## 居家窗边（Wan 3.0）

穿搭展示用。人物从颈部附近裁到膝盖以下，脸在画外；背景明亮，正面柔和暗部，身体边缘逆光；固定机位略低视角。同一场景拍多套衣服时，背景明暗和窗帘纹理容易不一致，要先确认场景一致。

# 选景

> **付费生成前必须出确认单。** 每次调用生图或生视频接口前，先用同级 `nuwa` 技能里的 `scripts/confirm_sheet.py` 渲染 HTML 确认单，在会话里给出可点击链接，等用户在对话里明确确认再提交。口头列参数不能代替确认单。只有用户本次说了"直接生成""不用问我"才跳过。细则见 [生成前确认](../nuwa/references/confirm-before-generate.md)。

选景决定这个模特在哪里、被怎么拍。和服装一样，场景也要能复用：同一个棚、同一种机位，可以拍很多套衣服。

## 对标优先

先让用户给一张对标图：真实拍摄的照片或视频截图，里面的构图、机位、光线就是想要的感觉。不要让我从文字或一张角度不明的参考里去推机位，推出来的总会有偏差。

## 从对标图里读出场景卡

逐项读出来，写进档案的 `场景/<场景名>.md`：

```markdown
# 场景：棚拍工作花絮

- 对标图：素材/外部参考/<文件名>
- 画幅：3:4 竖屏
- 背景：浅灰色无缝背景纸，墙面与地面弧形过渡，地面有使用痕迹
- 入画器材：左侧边缘一把大号银色反光伞，左下灯架腿，右下灯架轮子
- 光线：柔和的正面棚拍光，阴影很淡，画面略偏冷灰
- 机位：几乎正面（偏约 15°），腰部高度略微仰拍，手机手持轻微晃动
- 景别：全身，人物居中，占画面高约七成，头顶留白较多
- 人物视线：多数时候垂眼看左前下方，不看镜头
- 质感：真实手机花絮，轻微颗粒，不是广告大片
```

逐项写的原因：提示词里每一项都要单独写出来，模型才会照做。只写"摄影棚"，模型会自己决定背景颜色、器材和机位。

## 对标图怎么交给模型

| 做法 | 适合 | 风险 |
|---|---|---|
| 只用文字描述场景卡 | 大多数情况 | 细节可能和对标有出入 |
| 把对标图涂掉人物，只留场景，作为场景参考图 | 场景细节很重要时 | 涂抹痕迹可能被模型当成画面内容 |
| 先用图像模型合成首帧（模特 + 场景），再用首帧生视频 | 对构图要求最严格时 | 多一次生图，首帧要单独确认 |

不要把带着别人脸的对标图直接作为参考图上传。对标图里的真人会和模特的身份图抢"这个人长什么样"，已经生成过的视频首帧里那张漂移过的脸也一样。

## 器材入画和"不出镜"的写法

花絮类场景的真实感，很大程度来自画面边缘露出的器材。但"主摄影师不出镜"这类要求，只写"不出镜"往往不起作用，模型常常会在画面边缘补出相机和手。

有效的写法是**把画面边缘的内容写具体**，用具体内容占住那个位置：

```text
画面左侧边缘只露出银色反光伞和灯架，右下角露出灯架轮子。
画面里只有模特一个人，没有相机、手、手臂或任何其他人体部位。
```

改成这种写法后仍可能有手臂入画，生成后一定要检查画面边缘。

## 视频场景：先定空镜，再加道具，最后加人

人物要在场景里走动、和道具互动时，场景一步一步锁定，每步只解决一件事，哪步出错只重做哪步：

1. **用对标截图定光和空间结构。** 让用户给一张真实拍摄的截图，场景的光、纵深和人站在哪里都照它来，不靠文字去想象。
2. **出空镜。** 写实空镜优先用 Seedream（即梦）。同一段提示词，GPT Image 出的空镜明显更假：地面像刚下过雨，脏乱过头；Seedream 出的通常一张就能用。
3. **让用户在空镜上画标注。** 用画圈、箭头标出站位、走线、入画方向和道具位置，我按标注换算成画面百分比和离镜头的距离，写进提示词。
4. **把道具单独编辑进空镜。** 先不放人，确认道具的大小、接触阴影、地面倒影都对，这张「空镜＋道具」就是后面所有镜头的底图。道具摆成参考图里没有的姿态（比如躺倒）时，细节最容易崩，必要时先单独出一张那个姿态的道具参考。
5. **最后加人。** 加人的写法见 `nuwa-motion` 的「多镜头衔接」。

### 空镜提示词的规则

- **全文不出现人。** 除了「画面里没有人」这一句，不写站位上的人、舞者、头顶、双脚，连「假如站一个人」也不写，否则模型会真画出一个人。站位只用地面和家具来定，比如「画面正中那片空着的地板」。
- **像真实有人住的地方。** 布局合理有秩序：主体家具居中摆正，挂画挂正；生活感只来自一两样放在合理位置的物件（茶几上的书和水杯、沙发上的毯子），痕迹最多一点浮灰。不要为了「不完美」故意弄歪、弄乱，不写脚印、乱放的鞋，不写积水、雨后湿地，也不写老旧破败（锈迹、掉漆、撕掉的海报）。用户只是顺口提到的概念道具，没明确要求就不放。
- **光只写方向、软硬和明暗档位。** 不写冷暖和色温，留给后期调；物体本身的颜色（绿色地坪、蓝紫色氛围灯带）可以写。没有要求时不要默认用闪光快照的光。
- **纵深要浅，透视要统一。** 宽阔、背景很远的空间，前景会剩一大片空地，人站上去像在舞台上，很出戏。人离背景约 1 米、相机离人约 2.5～3 米，最接近真实的手机视频。提示词里写明「家具顶面、墙脚线、地面接缝都汇聚到同一条视平线，视平线在画面高度约 X%」，再写死站位落在画面的什么位置。
- **出图后检查透视。** 把地面接缝和天花板、家具的线条分别延长，看它们是不是交在同一条视平线上。不在同一条线上，地面就像斜着贴上去的，换图或改提示词。

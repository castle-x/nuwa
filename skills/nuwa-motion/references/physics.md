# 物理动态写法

真人感视频里最容易露馅的，是该动的地方不动：身体像一块硬壳，头发粘成一片，衣服像贴在身上的贴图。修这类问题的原则是：**不直白描述某个部位怎么动，而是要求一切都遵循真实的重量、惯性和重力。**

## 为什么这样写

- **直白的描述容易被拦，也容易被弱化。** 直接写身体部位"抖动"，内容审核可能拒绝，或者模型往保守的方向处理。
- **物理规律对模型的约束更有效。** "按真实的重量和惯性起伏、回弹、再稳定"给了模型一个可以执行的运动模型；"要自然"只是一个形容词。
- **一个原则管住三类东西。** 身体软组织、头发、衣料都是"有重量、会滞后、会回落"的东西，用同一套物理语言描述，动起来才协调。只管身体不管衣服，画面会出现身体在动、衣服僵着的割裂感。

## 原型写法

这个写法最早是三句话，分散在舞蹈复刻提示词的不同段落里（Wan 3.0，原文见 `nuwa-dance` 的示例提示词）：

```text
身体质感：身体质感真实。胸部、腰腹等柔软部位按真实的重量和惯性，随跳跃、扭转和停顿自然起伏和回弹，幅度和节奏与视频1中舞者的身体动态一致。文胸只有自然支撑作用，身体不能像固定的硬块一样僵住不动。
（人物段）黑色长直发，带碎发和长刘海，头发随动作自然甩动。
（画面段）动作连续自然，针织袖子、织带和裤腿随动作摆动。
```

## 通用模块

把上面三句合成一段，头发和衣料也写成物理过程：

```text
物理动态：整段动作遵循真实的重量、惯性和重力。
身体：胸部、腰腹、臀腿等柔软部位按真实的重量和惯性，随跳跃、扭转和急停自然起伏、回弹，再逐渐稳定{复刻时加：，幅度和节奏与视频1中人物的身体动态一致}。内衣只有自然支撑作用，身体不能像固定的硬块一样僵住不动。
头发：发丝有重量，随动作甩出时略微滞后于头部，停顿后自然回落、散开，不会粘成一片，也不会悬浮不落。
服装：衣料按各自材质的重量和垂坠感响应动作。{逐件写，比如：针织袖子随手臂摆出后回落，织带和裤腿随步伐甩动并略微滞后}。动作停下后，衣料在一两拍内慢慢静止，不能像贴在身上的贴图，也不能无风自飘。
```

配套的负面提示词（模型支持时）：

```text
身体僵硬，塑料质感，躯干像固定模型，软组织不动，头发粘成一片，头发悬浮，衣料僵硬，衣服像贴图，无风自飘，动作卡顿
```

## 写的时候注意

- **动作越大，越需要这一段。** 舞蹈、跳跃、转身时必加；站着换姿势这类小动作，写"衣料随动作产生细小褶皱"就够了，写多了反而会让模型加戏。
- **复刻时跟着参考视频。** "幅度和节奏与视频1一致"这句最关键，它让模型把参考视频里真实的身体动态也当成要复刻的内容，而不只是对齐骨骼姿态。
- **衣料要写材质。** 针织、帆布、雪纺、牛仔的垂坠和摆动完全不同。从衣橱条目的服装描述里取材质词。
- **不写具体部位怎么抖。** 只写重量、惯性、回弹、稳定这些物理过程。

这个写法针对 Wan 3.0。换模型时先跑一个短片段确认效果。

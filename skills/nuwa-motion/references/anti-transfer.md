# 防止参考视频的外观被带进成品

## 问题

做视频复刻时，模型默认参考视频里的一切都要复刻，不只是动作。参考视频里舞者戴的手套、帽子、首饰、外套，甚至发色、纹身，都可能被带到模特身上。

例如：模特的参考图里双手是裸露的，参考视频里的舞者戴着黑手套，成品里模特也戴上了黑手套。

## 解法：复刻前先列一张外观差异清单

只靠一句"视频1只提供动作"不够，模型对笼统的排除不敏感。要先找出参考视频里**和模特不一样的每一个外观元素**，然后逐个点名处理。

### 第一步：看参考视频，列出差异

抽几帧（开头、中间、动作最大的地方），逐项对比参考视频里的人和模特的成品图：

| 检查项 | 参考视频里有什么 | 模特身上是什么 |
|---|---|---|
| 手部 | 手套、戒指、美甲、手链 | |
| 头部 | 帽子、发箍、眼镜、耳饰 | |
| 头发 | 发色、长度、发型 | |
| 上装、下装、鞋 | 款式、颜色 | |
| 外层 | 外套、披肩、围巾 | |
| 皮肤 | 纹身、肤色 | |
| 手持物 | 道具、麦克风、扇子 | |
| 场景 | 背景、地面、灯光 | |

### 第二步：逐个写进提示词

每一个差异项写两句：先用肯定的说法写模特**是什么样**，再点名写参考视频里的东西**不迁移**。

```text
双手：手部完全裸露，是自然肤色，没有戴手套。即使视频1中的舞者戴着黑手套，也不能把手套迁移到模特身上。
```

肯定的那句更重要。只写"不要手套"，模型仍然注意到了"手套"这个概念；先写"手部完全裸露，是自然肤色"，模型就有了一个明确的目标。

### 第三步：总的排除句放在开头

```text
视频1只提供舞蹈动作、动作顺序、节奏、身体朝向和身体动态，不提供人物外貌、服装、配饰或场景。
```

### 第四步：负面提示词点名

模型支持负面提示词时，把差异项直接列进去，并带上颜色：

```text
手套，黑色手套，深色手部
```

### 第五步：提交参数

Wan 3.0 的 `prompt_extend` 保持 `false`。打开后模型会自动扩写提示词，可能参考视频里的外观又被加回来。

## 提示词约束不够时

| 做法 | 适用 |
|---|---|
| 换一段参考视频 | 有动作相近、外观更干净的视频可选时 |
| 裁掉参考视频里外观差异明显的片段 | 差异只在某几秒出现时 |
| 重新生成一次 | 偶发迁移 |
| 后期处理 | 迁移面积很小，比如只在手部 |

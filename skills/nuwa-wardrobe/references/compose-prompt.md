# 合成提示词框架

这个结构在 ChatGPT 网页版（GPT Image）上效果稳定：头身比例自然，真实感强。在这个模型上，除了 `{服装描述}`，其余部分逐字复用，不要每次改写。

换成其他模型时，这个框架只是起点：先查 [模型能力速查表](../../nuwa/references/model-capabilities.md) 看那个模型的长处和短处，再调整写法，并把结果回写。比如 GPT Image 在自己的成图上反复修改会重绘面部，换到 Nano Banana Pro 上合成，参考图的权重和表述方式可能都要变。

## 框架

```text
模特参考图{模特图编号}，服装身材姿势参考图{服装图编号}，{输出形式}真人形象照，{背景}棚拍背景。{服装描述}

要求还原真实的人物皮肤肢体衔接细节。

头身比例自然，
禁止大头娃娃和超小头娃娃，假人，过度磨皮、油腻，禁止脏噪点，禁止肢体衔接处的人偶线条。
```

## 每个槽位

| 槽位 | 填法 |
|---|---|
| `{模特图编号}` | 面部锁定图的上传顺序编号 |
| `{服装图编号}` | 服装图的上传顺序编号 |
| `{输出形式}` | 默认穿衣三视图（3:2，正面全身＋背面或侧面全身＋带头半身特写，版式见 SKILL.md ⓪ 第3项）；用户明确要单张时才留空 |
| `{背景}` | 浅灰色、米白色等，和后续要用的场景一致 |
| `{服装描述}` | 按 [服装描述结构](garment-description.md) 提取的整段描述 |

## 每一句为什么要留着

- **"服装身材姿势参考图"**：服装图同时负责服装、身材和姿势。这是不出现大头的关键：头身比例只有一个来源，模型只需要把脸放到一个比例已经确定的身体上。
- **"真人形象照"**：把输出定位成真实拍摄的人像照，而不是时装插画或产品图。
- **"还原真实的人物皮肤肢体衔接细节"**：服装图常常是假人，肩、肘、腰的衔接处容易留下假人的接缝。
- **"禁止大头娃娃和超小头娃娃"**：两个方向都要禁，只禁一个，模型会往另一个方向偏。
- **"假人""肢体衔接处的人偶线条"**：防止假人的塑料质感和关节线迁移到真人身上。
- **"过度磨皮、油腻、脏噪点"**：分别对应 AI 人像最常见的三种质感问题：太光滑、太油亮、太脏。

## 服装图不带完整身体时

服装图是平铺图、挂拍图或无头裁图时，它提供不了身材和姿势。这时把开头改成：

```text
模特参考图{模特图编号}，服装参考图{服装图编号}，身材比例参考图{比例图编号}，……
```

并在比例来源图上按 `nuwa-body` 写明头身比。这种组合尚未经过和上面框架同等程度的验证，生成后要特别检查头身比。

## 要拿去生视频时

看后面要拿它做什么：

- **做视频复刻**：成品的视角、构图、机位要尽量和参考视频一致，对不上人物会畸变（Wan 系列有这个问题）。参考视频是正面平视，就合成一张正面平视的全身照。
- **做概念文生的视频**：一张头身比例正确的全身照就够了。
- **三视图**：适合核验多角度的一致性、作为衣橱存档。要拿去做视频时，挑和参考视频视角对得上的那一格单独用。

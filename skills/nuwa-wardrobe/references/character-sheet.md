# 四宫格定妆图（可选）

把脸、妆容、发型和一整套服装放进一张竖版图里，给视频生成或对外沟通用。它不替代面部锁定图和成品全身图：身份依据仍然是锁定图，后续视频优先用成品全身图。

## 什么时候用

- 要给一个造型出"定妆照"，让用户一次看全脸、侧脸、正面服装和背面。
- 视频模型只能传一张图，又需要它同时看到脸和整套衣服。
- 多个模特时每人单独一张，不要把几个人放进同一张。

## 输入分工

```text
面部锁定图（定稿）──────────── 身份：五官、骨相、年龄、肤色基底、标志特征 ─┐
服装图或无头裁图 ───────────── 身材比例、服装、配饰、鞋                      ├→ 四宫格 → 核验 → 归档
妆容示例 → 观察 → 文字描述 ─── 妆容和肤质，只用文字，不上传示例图            │
空白布局图（可选）───────────── 只有分区和线条，帮模型守住布局               ─┘
```

- 面部锁定图是 GPT Image 的定稿，这里喂回去一次属于正常的往下传，记录里写明。定妆图不满意时回到锁定图重出，不在定妆图上改。
- 无头裁图要检查：头部完全裁掉，双肩和衣服保留，没有混进旁边的分区。
- 妆容示例里那个人的脸不能进模型。先看懂腮红、唇、眼妆、高光、肤质，写成文字，写法见 `nuwa-casting` 的 [妆容](../../nuwa-casting/references/makeup.md)。

## 提示词模板

```text
生成一张真人照片质感的成年角色定妆参考图。

参考分工：图片{身份图编号}决定这个人的五官结构、眼型和眼距、鼻、唇、下颌、年龄、标志特征和肤色基底，每一格都必须是她本人。图片{服装图编号}是无头图，只提供身体比例、服装、配饰和鞋；没有头只是因为裁掉了，头和脸完全以图片{身份图编号}为准。
发型：{发型描述}。
妆容和肤质（只按文字）：{妆容描述}。
服装与配饰：{服装描述}。
身体比例：{身体比例}。参考图里看不到的服装部分，按看得到的结构简单、连贯地补全。

1. 画布与布局：竖版画布，两列两行，列宽相等，分割线细而直。上排正好占画布高度的 1/3，下排占 2/3。以 1024×1536 为例，横线在 y=512，竖线在 x=512，上排两格是正方形。完整发型要落在格子里。
2. 上排是面部：左上正面头肩照，右上严格 90 度正侧面头肩照，都能看到完整发型。忠实保留面部结构、妆容和表情。
3. 左下是放大的正面服装：放松、左右对称的 A 字站姿，双臂略微离开身体；从脖子以下取景到鞋底，头部完全在格子外；双肩、双手、全部衣服和鞋都在；人物明显比右下的背面人物大，填满这一格。
4. 右下是背面全身：背对镜头的 A 字站姿，从发顶到鞋底完整落在格内，全身比例自然；展示完整的背面发型、服装结构和鞋。
5. 一致性与摄影：每一格是同一个人、同一套衣服配饰、同一副身体比例。中性灰无缝棚拍背景，统一柔和的三点布光和曝光。真实的织物纹理和自然褶皱。不要文字、场景道具、动态姿势、塑料皮肤、CGI 或插画感。
```

这里的分割线是有意画的：四格景别不同，没有线时模型容易把四格融成一个场景。面部锁定图不画线，是因为它要被反复当参考图上传，线会让下游模型读成拼贴；定妆图一般只给人看或给视频模型当单张参考，两者用途不同。

肤质写法按模型调整：GPT Image 只写"自然干净的照片肤质"，不写毛孔、绒毛、微纹理这类词，否则容易出噪点和脏灰调；Nano Banana 系列可以写具体的细节词。见 `nuwa-casting` 的 [画质与真人感](../../nuwa-casting/references/realism.md)。

## 核验

- 身份、身材、服装、妆容是否都和输入一致；侧面是不是严格 90 度。
- 左下是否真的没有头，右下是否从发顶到鞋底完整。
- 妆容单独看：腮红位置和浓度、唇部反光、高光分布、肤色。
- 用像素量分割线位置。提示词和布局图都保证不了精确的 1/3，达不到就写明实际比例，不要说"精确完成"。需要精确排版时，征得同意后再后处理，等比例缩放分区内容，并重新检查发型、手脚和鞋是否完整。
- 定妆图本身不保证后续生成的身份一致，后续每次输出仍要核验。

## 记录

提示词原文、每张输入图的路径职责和来源（锁定图写明是第几次回喂）、模型实返标识、实际像素、用户验收状态，写进生成记录。缺的字段写"待核实"。

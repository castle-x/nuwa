# 服装描述结构

看服装图时按这份结构提取。它来自一段已经验证有效的服装描述（见 [示例](examples.md)）：那段描述之所以锁得住，一是顺序固定，二是写了每件衣服**怎么穿在身上**，而不只是写有哪些单品。

## 六段固定顺序

| 顺序 | 写什么 | 写法要点 |
|---|---|---|
| 1. 上装 | 颜色 + 材质 + 品类 → 版型 → 穿法和状态 → 褶皱堆在哪里 → 细节 | 状态写具体位置：滑落到"双肩下方"，堆在"上臂和手肘处"，敞开后"在胸部下方向上堆起" |
| 2. 内搭 | 品类 → 从哪里露出来 → 和外层的对比 | "一只肩膀上露出黑色细吊带的肩带，与滑落的灰色针织形成对比" |
| 3. 下装 | 腰位 + 颜色 + 风格 + 品类 → 穿着状态 → 腰头和口袋细节逐项 → 不对称的地方 | 腰位要写（超低腰、高腰），状态要写（松垮挂在胯部）；腰头的面料、拼接、织带、缝线、五金逐项列出 |
| 4. 鞋与配件 | 位置 + 品类 + 颜色 | 配件写挂在哪里："腰头侧边有深色垂坠肩带和黑色工装小包" |
| 5. 整体风格 | 一句话 | "随性又刻意打造的凌乱叠穿风格" |
| 6. 物理质感 | 一句话 | "真实的布料垂坠感，自然受重力影响的褶皱，逼真的针织与帆布质感" |

## 看图时逐项检查

- **每一件**：品类、主色和辅色、材质与织法（罗纹针织、帆布、牛仔、雪纺）、版型（宽松、修身、超长袖、短款）。
- **穿着状态**：滑落、敞开、堆叠、外翻、卷起、松挂、塞进去还是放出来，各自在身体的哪个位置。
- **褶皱和堆积**：在手肘、胸下、腰头、裤脚等位置的堆积和褶皱走向。
- **细节**：破损、刺绣、蕾丝、五金（D 形环、扣子、拉链）、缝线、拼接、翻盖、口袋。
- **露肤位置**：露肩、露腰、露腹，露到哪里为止。
- **左右不对称**：只有一侧露肩带、腰头只有一边外翻、一侧露出内层布料。这些不对称是"真实穿着感"的来源，最容易在合成时被模型抹平。

## 不要写的东西

- **品牌名和 logo 文字。** 模型会试图把字画出来，几乎都会写错。描述成"白色松紧腰带，带黑色字母印花"就够了。
- **图里看不到的部分。** 服装图只有正面时，不要猜背面长什么样；需要背面时让模型"按可见结构简单、连贯地延伸"。
- **空泛的评价词。** "时尚、高级、有设计感"不提供任何可执行的信息。
- **人的长相和身材。** 服装描述只描述衣服。长相交给身份图，身材交给比例来源图。

## 输出格式

输出一段连续的中文描述，按六段顺序写，不分条、不加标题，可以直接粘进合成框架的 `{服装描述}` 位置。写完自查一遍：把描述读给一个没看过图的人，他能不能画出这套衣服在身上的样子，尤其是哪里松、哪里堆、哪里不对称。

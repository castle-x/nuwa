# 衣橱与服装合成

> **付费生成前必须出确认单。** 每次调用生图或生视频接口前，先用同级 `nuwa` 技能里的 `scripts/confirm_sheet.py` 渲染 HTML 确认单，在会话里给出可点击链接，等用户在对话里明确确认再提交。口头列参数不能代替确认单。只有用户本次说了"直接生成""不用问我"才跳过。细则见 [生成前确认](../nuwa/references/confirm-before-generate.md)。

这一环把"一个人"和"一套衣服"合成一张真人感的全身照。合成好的成品全身图会成为视频生成时最重要的参考：它同时决定了身份、服装和身材比例。

## 有参考图时，文字要克制

参考图已经能交代清楚的东西，提示词里只写「照参考图N」，不要再用文字描述细节。文字写得越细，越会和参考图互相较劲，模型会照着文字重画，结果反而离参考图更远。脸、身材、服装都是这样：

- **脸**：写了眼线、唇形这类妆容细节，脸就会变成别人（见下文「妆容先问用户」）。
- **身材**：只说身材参考图负责哪几项（比例、腹部形态），不要再用文字去描述具体的形态。
- **服装**：只点名有哪几件，款式、开口、扣带、印花都交给服装图。

**不写「内衣不要」「内裤不要」这类话。** 身材参考图上的人通常穿着打底衣物，提示词里一写「把内衣去掉」，即使本意是换成服装图的衣服，审核也会判成脱衣，直接拦下。要么不提参考图上穿的是什么（「参考图2只提供身材」已经够了），要么换成不敏感的叫法，例如「参考图2身上那套灰色运动上衣不要」。

文字只写三类内容：几张参考图各自负责什么；哪里要和参考图不一样（例如「裤子的腰位不照参考图3」）；参考图给不了的东西（场景、光线、构图、机位）。改图时也一样：成图出了问题，先查是不是文字和参考图在打架，或者哪一句把模型拉回了参考图，不要往上继续加描述。

## 流程

```text
⓪ 看完图，一次问齐妆容、遮脸部件、输出形式、模型
服装图 ──→ ① 看图提取结构化服装描述 ──┐
面部锁定图（casting）─────────────────┼──→ ③ 套进合成框架 ──→ ④ 生成 ──→ ⑤ 核验 ──→ ⑥ 记入衣橱
② 确认比例来源（body）────────────────┘
```

### ⓪ 动笔前一次问齐

看完服装图、写提示词之前，把下面几项放在一次提问里问完，每项一题。有提问工具时（如 Claude Code 的 AskUserQuestion）用它，推荐项放第一个并标上「推荐」。每个选项后面写清选了会怎样，用户不用回看上下文也能选。本次对话里用户已经说清的项不再问。

1. **妆容**：要不要写更多妆容，并说明写了可能改变她的面貌。推荐「不写妆容」，备选「只写颜色级」。原因见下文「妆容先问用户」。
2. **会遮脸或改变头部轮廓的部件**：面罩、口罩、墨镜、帽子、兜帽、头饰、面纱等，有几件问几件。推荐「移开但保留」（拉到脖子上、推到头顶、兜帽放下），备选「照原样戴」（注明被遮住的部位没法核验像不像）和「不要」。服装图里没有这类部件就不问。
3. **输出形式**：**默认出穿衣三视图，不再默认出单张或其他版式**（用户 2026-11-17 定，原话「以后尽量不要默认做三视图以外的穿衣版本了」）。三视图版式同 `nuwa-body` 的身材锁定图：3:2 横图一行三格，左边两格各占约 22% 宽，是正面全身和背面全身（或正面＋严格 90° 侧面，按下游需要选）；右边约 56% 宽是**带头**的正面半身特写，从头顶拍到胯部或腰腹，用来看脸和皮肤。这一项不用问，只问第二格要背面还是侧面（按角色身材锁定图采用的那版给推荐）。用户明确要单张全身或四格定妆图时才出别的版式。单张 2:3 全身在网页版只有约 1024×1536，皮肤细节撑不住（Milo桃桃 2026-11-17 第1版实测，用户反馈「分辨率好像不够，皮肤细节不足」）。
4. **模型和谁来跑**：用户在 ChatGPT 网页版自己跑 GPT Image（首选，理由见 ④），还是由 Agent 调接口跑其他模型。这一项决定确认单上的通道和提示词写法。

提问时先说从图里看到了什么，例如「服装图领口有一块银灰色带红纹的金属面罩」，不要笼统地问「有没有特殊部件」。

图里有看不准的地方，例如一块浅色区域是露出的皮肤还是打底衣、一根带子属于衣服还是道具，不放进这轮提问。按最可能的理解写进提示词，在确认单备注里写明这个理解，交单时请用户核对。

### ① 提取服装描述

自己看服装图，按 [服装描述结构](references/garment-description.md) 把这套衣服看清楚：有哪几件、怎么穿、哪里不对称。看清楚是为了三件事：在 ⓪ 里问对问题，在 ⑤ 里逐项核验，在 ⑥ 里记进衣橱。

服装图会作为参考图上传时，这段描述不要整段放进提示词，按上面「有参考图时，文字要克制」，服装字段只点名有哪几件，外加要和图不一样的地方。只有服装图传不了、只能靠文字交代这套衣服时，才把整段描述放进提示词。

服装描述是这套衣服专属的，所以每套衣服都要重新提取。通用的是提取的结构和清单，不是某一段描述。

### ② 确认比例来源

服装图里如果有完整的身体（真人模特或假人），直接让它负责服装、身材和姿势。这是最稳的组合，不会出现大头。服装图是平铺图、挂拍图或无头裁图时，按 `nuwa-body` 另外指定比例来源。

### ③ 套进合成框架

把服装部分填进 [合成提示词框架](references/compose-prompt.md)：服装图会上传时，只填点名的部件清单；服装图传不了时，才填 ① 的整段描述。框架的其余部分（参考分工、真实感要求、负面约束）是通用的，不要每次改写。

### ④ 生成

先确认用户这次能用哪个模型和通道。首选 ChatGPT 网页版（GPT Image）。GPT Image 走 CPA 反代时审核极严，常规服装都可能被拦，服装合成走网页版。换其他模型时，先查 [模型能力速查表](../nuwa/references/model-capabilities.md)。

**成图回喂要克制。** 面部锁定图本身是 GPT Image 的定稿，拿来做穿衣合成是正常的往下传一步，记录里写明即可。合成结果不满意时，不要把这张合成图再喂回 GPT Image 继续改：每改一轮都可能重绘面部，越改越不像本人。回到面部锁定图和服装图，只改提示词里有问题的那一句重新生成；只是局部问题（一颗扣子、一处褶皱）交给 Nano Banana Pro 改。用户坚持在 GPT 成图上改，先提醒风险再照做，并在生成记录里写明第几次回喂。规则见 [参考分工](../nuwa/references/reference-roles.md) 的"选模型与成图回喂"。

**皮肤真实感靠文字锁定。** 穿衣合成的「皮肤」字段固定放活人血色皮肤句（`realistic-character-design` 的 `references/production/prompt-real-person.md`）：脸部句和身体句合并，只留画面里看得见的部位，后面接去油光句。三视图的特写格焦点放在眼睛，写明脸和露出的身体部位皮肤纹理清楚（用户 2026-11-17 定）。

**妆容先问用户，默认少写。** 给模特穿衣服（合成定妆图、或拿定妆图驱动视频）时，提示词里写得越细的妆容（眼线形状、内眼角勾线、睫毛、唇形），越容易把脸改成别人，会崩脸。大模型习惯主动补一套贴合服装的妆容，不要这样做。写提示词前先问用户一句（放在 ⓪ 那一轮提问里）：「要不要写更多妆容？写了可能会改变她的面貌。」用户不要就不写，或只留一种颜色级的描述（例如「淡紫色眼影」）。只留颜色级描述时，脸最接近参考图。

生成前把提示词原文、两张参考图及其编号、输出形式（默认穿衣三视图）、模型讲清楚，等用户确认。图编号必须和实际上传顺序一致，模特图先传就是图片1，服装图先传服装图就是图片1。

### ⑤ 核验

- 脸是不是模特本人，和面部锁定图对比。
- 头身比是否自然，按 `nuwa-body` 的方法量一下。
- 服装逐项对照服装描述：每个状态（滑落、堆叠、外翻）和每个细节（五金、织带、破损）都在不在。
- 肢体衔接处有没有假人的关节线，皮肤是否过度磨皮或油腻。
- 三视图模式下，三格是不是同一个人、同一套衣服。

### ⑥ 记入衣橱

用户认可后，在档案的 `衣橱.md` 加一条：

```markdown
## 造型 03：灰针织开衫 + 工装阔腿裤

- 服装原图：素材/外部参考/<文件名>
- 服装描述：<提取出的完整描述，原文>
- 成品图：素材/定稿/<文件名>（单人全身照，生视频用；三视图，核验和存档用）
- 合成模型：<模型>，<日期>
- 适合场景：棚拍、街拍
- 用户评价：<原话>
- 状态：可用于视频 / 待修改
```

## 四宫格定妆图（可选）

需要一张图同时看全脸、侧脸、正面服装和背面时（定妆照、只能传一张图的视频模型），出四宫格定妆图。它不替代面部锁定图和成品全身图。模板和核验见 [四宫格定妆图](references/character-sheet.md)。

## 选衣服时要想到视频

挑衣服不只看静态好不好看，还要看它进了视频会不会出问题：

- **轮廓要清楚。** 深浅搭配、长短对比明显的衣服，快切时一眼能认出是哪一套。
- **要能看出动态。** 袖口、下摆、腰头、裤腿这些会随动作摆动的部分，能让视频显得真实。
- **复杂结构是风险。** 细链、网纹、多层叠穿、很多五金件，每一个都要在视频里保持数量和位置不变，穿帮的概率更高。
- **道具先定去留。** 包、提带、杯子会带来持握、受力、遮挡的问题。展示衣服不依赖的道具，在合成阶段就拿掉，不要留到视频里再去掉。

## 常见问题

| 现象 | 处理 |
|---|---|
| 衣服细节丢了或被简化 | 服装描述里缺了这一项，或者只写了品类没写状态。回到 ① 补全 |
| 衣服被"整理"得太整齐 | 补写凌乱、堆叠、不对称这些状态，并加"随性又刻意打造的凌乱叠穿" |
| 出现假人关节线、塑料皮肤 | 确认负面约束里有"假人""肢体衔接处的人偶线条" |
| 头偏大 | 比例来源不对，见 `nuwa-body` |
| 被安全审核拒绝 | 如实记录拒绝原话。服装里有泳装、内衣这类敏感部件时，提示词里不点名这些部件，也不写露肤范围，只写「外套里面的搭配照参考图N」，交给参考图去还原；身材字段按上文「不写去掉某件贴身衣物」处理。不另换近义词去绕。删掉这些后仍被拒，说明是参考图本身触发的，要另外处理 |
| 裤腰被提高，看不到髋骨线条 | 服装图里裤子的腰位比文字的权重高，人台上穿的是高腰，成图就会被拉回高腰。服装字段要写明「裤子的腰位不照参考图N」，再用一句整体要求说低腰（挂在胯上，裤腰前沿明显低于肚脐，髋骨突起露在裤腰上方）；优先级里不要写「各部件的位置不走样」，它会把腰位拉回去 |
| 露出的腹部被抹平，看不出线条 | 两个原因。一是身材字段只写了比例，没写腹部形态：加一句腹部形态照身材参考图（竖线、髋骨这类看得见的起伏）。二是正面平光会抹掉起伏：露腹的造型把光线改成柔光箱从侧上方约 45 度斜打 |
| 露脐装的肚脐崩坏（定妆图和视频都出现过） | 露脐装默认给模特加一枚脐钉，用它把肚脐的位置和形状钉住（用户 2026-11-17 定）。写在服装字段，一句即可：「肚脐上戴一枚银色弯杆脐钉：一颗小银珠在肚脐上缘的皮肤上，一颗稍大的银珠落在肚脐窝口。」样式参考图太小时只用文字，不上传。同一角色的脐钉样式固定，写进角色的衣橱或锁定设定，做视频时沿用同一句 |

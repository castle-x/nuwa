# 衣橱与服装合成

这一环把"一个人"和"一套衣服"合成一张真人感的全身照。合成好的成品全身图会成为视频生成时最重要的参考：它同时决定了身份、服装和身材比例。

## 流程

```text
服装图 ──→ ① 看图提取结构化服装描述 ──┐
面部锁定图（casting）─────────────────┼──→ ③ 套进合成框架 ──→ ④ 生成 ──→ ⑤ 核验 ──→ ⑥ 记入衣橱
② 确认比例来源（body）────────────────┘
```

### ① 提取服装描述

自己看服装图，按 [服装描述结构](references/garment-description.md) 输出一段描述。这一步是整个环节的关键：结构化的服装描述能把一致性锁住，合成出来的衣服和服装图几乎一样。

服装描述是这套衣服专属的，所以每套衣服都要重新提取。通用的是提取的结构和清单，不是某一段描述。

### ② 确认比例来源

服装图里如果有完整的身体（真人模特或假人），直接让它负责服装、身材和姿势。这是最稳的组合，不会出现大头。服装图是平铺图、挂拍图或无头裁图时，按 `nuwa-body` 另外指定比例来源。

### ③ 套进合成框架

把服装描述填进 [合成提示词框架](references/compose-prompt.md)。框架的其余部分（参考分工、真实感要求、负面约束）是通用的，不要每次改写。

### ④ 生成

先确认用户这次能用哪个模型和通道。首选 ChatGPT 网页版（GPT Image）。GPT Image 走 CPA 反代时审核极严，常规服装都可能被拦，服装合成走网页版。换其他模型时，先查 [模型能力速查表](../nuwa/references/model-capabilities.md)。

**成图回喂要克制。** 面部锁定图本身是 GPT Image 的定稿，拿来做穿衣合成是正常的往下传一步，记录里写明即可。合成结果不满意时，不要把这张合成图再喂回 GPT Image 继续改：每改一轮都可能重绘面部，越改越不像本人。回到面部锁定图和服装图，只改提示词里有问题的那一句重新生成；只是局部问题（一颗扣子、一处褶皱）交给 Nano Banana Pro 改。用户坚持在 GPT 成图上改，先提醒风险再照做，并在生成记录里写明第几次回喂。规则见 [参考分工](../nuwa/references/reference-roles.md) 的"选模型与成图回喂"。

**妆容先问用户，默认少写。** 给模特穿衣服（合成定妆图、或拿定妆图驱动视频）时，提示词里写得越细的妆容（眼线形状、内眼角勾线、睫毛、唇形），越容易把脸改成别人，会崩脸。大模型习惯主动补一套贴合服装的妆容，不要这样做。写提示词前先问用户一句：「要不要写更多妆容？写了可能会改变她的面貌。」用户不要就不写，或只留一种颜色级的描述（例如「淡紫色眼影」）。只留颜色级描述时，脸最接近参考图。

生成前把提示词原文、两张参考图及其编号、输出形式（单张或三视图）、模型讲清楚，等用户确认。图编号必须和实际上传顺序一致，模特图先传就是图片1，服装图先传服装图就是图片1。

### ⑤ 核验

- 脸是不是模特本人，和面部锁定图对比。
- 头身比是否自然，按 `nuwa-body` 的方法量一下。
- 服装逐项对照服装描述：每个状态（滑落、堆叠、外翻）和每个细节（五金、织带、破损）都在不在。
- 肢体衔接处有没有假人的关节线，皮肤是否过度磨皮或油腻。
- 三视图模式下，三格是不是同一个人、同一套衣服。

### ⑥ 记入衣橱

用户认可后，在档案的 `衣橱.md` 加一条：

```markdown
## 造型 03：灰针织开衫 + 工装阔腿裤

- 服装原图：素材/外部参考/<文件名>
- 服装描述：<提取出的完整描述，原文>
- 成品图：素材/定稿/<文件名>（单人全身照，生视频用；三视图，核验和存档用）
- 合成模型：<模型>，<日期>
- 适合场景：棚拍、街拍
- 用户评价：<原话>
- 状态：可用于视频 / 待修改
```

## 四宫格定妆图（可选）

需要一张图同时看全脸、侧脸、正面服装和背面时（定妆照、只能传一张图的视频模型），出四宫格定妆图。它不替代面部锁定图和成品全身图。模板和核验见 [四宫格定妆图](references/character-sheet.md)。

## 选衣服时要想到视频

挑衣服不只看静态好不好看，还要看它进了视频会不会出问题：

- **轮廓要清楚。** 深浅搭配、长短对比明显的衣服，快切时一眼能认出是哪一套。
- **要能看出动态。** 袖口、下摆、腰头、裤腿这些会随动作摆动的部分，能让视频显得真实。
- **复杂结构是风险。** 细链、网纹、多层叠穿、很多五金件，每一个都要在视频里保持数量和位置不变，穿帮的概率更高。
- **道具先定去留。** 包、提带、杯子会带来持握、受力、遮挡的问题。展示衣服不依赖的道具，在合成阶段就拿掉，不要留到视频里再去掉。

## 常见问题

| 现象 | 处理 |
|---|---|
| 衣服细节丢了或被简化 | 服装描述里缺了这一项，或者只写了品类没写状态。回到 ① 补全 |
| 衣服被"整理"得太整齐 | 补写凌乱、堆叠、不对称这些状态，并加"随性又刻意打造的凌乱叠穿" |
| 出现假人关节线、塑料皮肤 | 确认负面约束里有"假人""肢体衔接处的人偶线条" |
| 头偏大 | 比例来源不对，见 `nuwa-body` |
| 被安全审核拒绝 | 如实记录拒绝层级，不换说法硬绕；涉及身体的描述改用中性写法 |

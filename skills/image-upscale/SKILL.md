# 图片转高清（保真超分）

只放大、不重绘：模型学的是"让放大结果缩回原图时和原图一致"，所以不会改五官、表情、发型。代价是它不会凭空加细节，原图里没有的东西放大后也没有。

## 第一步：确认环境

本 skill 的脚本都在 `scripts/` 下，下面用 `<skill>` 指本 skill 所在目录。

先运行安装脚本，已装好时几秒就结束：

```bash
python3 <skill>/scripts/setup.py
```

Windows 上把 `python3` 换成 `py`。首次安装要下载 PyTorch（Mac 约 300MB，NVIDIA 版约 2.5GB）和三个模型（共约 250MB），装到 `~/.image-upscale`，告诉用户需要几分钟。

- 没有 Python 3.10+ 也没有 uv 时，脚本会提示安装 uv（`https://docs.astral.sh/uv/`）。让用户装好再重试，不要替用户改系统 Python。
- GTX 10 系等老 NVIDIA 显卡：加 `--cuda cu128`。
- 最后一行会打印检测到的设备。出现 `cpu` 但用户有 NVIDIA 显卡，说明装成了 CPU 版，先排查 `nvidia-smi` 是否可用。

## 第二步：选模型和参数

| 情况 | 参数 |
|---|---|
| 默认：人像、AIGC 出图、锁脸图、身材图，以及送视频模型的帧 | `-m hat`（默认 `--blend 0`，不写参数也是它） |
| 压缩很重的网图、截图，HAT 放大后出现明显块状或假纹理 | `-m dat2`（默认 `--blend 0.2`） |
| 一批图先快速看效果 | `-m plksr` |
| 用户说电脑卡、内存小、不着急 | 加 `--eco`（峰值约 2GB，慢一倍左右，画质几乎不变） |

**为什么默认 HAT**（用户 2026-11-17 定）：同一张 GPT Image 人脸四视图放大到 2560，DAT2（blend 0.2）回投影 46.87dB，雀斑变淡、毛孔被抹平，像磨了一层皮；HAT（blend 0）63.51dB，雀斑和毛孔基本保住。身材三视图同样：DAT2 47.71dB，HAT 65.24dB。代价是 HAT 慢一倍左右，Mac 上显存峰值约 10.8GB（DAT2 约 5.8GB）；内存紧张时加 `--eco`。

目标尺寸用 `--target` 指定长边：2K=2560，4K=3840，8K=7680。不指定就放大 4 倍。

`--blend` 把模型结果和普通插值按比例混合，用来压掉模型造出的假纹理（发丝、布料上细碎的"脏"纹理）。用户嫌结果"太锐、有颗粒、像油画"时调到 0.3；嫌"不够清楚"时调到 0.1 或 0。

## 第三步：运行

```bash
python3 <skill>/scripts/upscale.py 图片或文件夹 -o 输出目录 --target 3840 --check --compare
```

- 输出文件名形如 `原名_hat_3840.png`。
- `--check` 打印回投影 PSNR，并输出差异热图 `*_diff.png`。
- `--compare` 生成拖动对比网页 `*_compare/index.html`，用浏览器打开就能拖中线看前后差别，可缩放到 100%/200%。

处理时间参考（约 1500×1000 放大到 4K）：DAT2 在 Apple M 系列 Pro 上约 1～2 分钟，HAT 约慢一倍，RTX 4060 Ti 级别显卡预计十几到几十秒，纯 CPU 可能要十几分钟以上。CPU 上先告诉用户会很慢，建议换 `-m plksr`。批量处理时在后台运行，不要阻塞对话。

## 第四步：检查和汇报

1. **看回投影 PSNR。** 40dB 以上说明结果和原图高度一致；35dB 以下说明模型改动明显，打开差异热图看亮的地方是不是在脸上。HAT 很少低于 40dB；用 DAT2 时亮在脸上就换回 HAT 重跑。
2. **看脸。** 有看图能力时，把结果里的脸部裁出来，和原图同区域放大后对比，确认五官没变。
3. **汇报**：输出文件路径、尺寸、耗时、PSNR，和对比页路径。不要说"细节被增强/修复了"，这个方案只是更清晰的放大。

## 能力边界，提前告诉用户

- **脸太小救不回来。** 原图里脸只有几十像素宽时，放大后仍然偏糊，但不会变形。用户要的是"把小脸变清楚"，只有生成式方案能做到，而那类方案一定会改脸，让用户自己取舍。
- **不去水印、不修划痕、不改构图。**
- **8K 文件很大**（PNG 常见 50～100MB）。只是看图或发社交平台，4K 就够。
